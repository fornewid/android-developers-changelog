Try the Compose way

Jetpack Compose is the recommended UI toolkit for Android. Learn how to add notifications in Compose.

[Notifications →](https://developer.android.com/develop/ui/compose/notifications)

![](/static/images/android-compose-ui-logo.png)

Notifications allow your app to provide users with timely information and
reminders even when the app isn't explicitly in use. In View-based apps, you use
the Android system APIs and `NotificationCompat` to create and post
notifications.

For a comprehensive overview of the Android notification system, including
where notifications appear, their anatomy, and system-wide behaviors, see the
[About notifications](/develop/ui/compose/notifications) guide.
