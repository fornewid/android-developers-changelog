## Android XR Engine Hub

A desktop tool for streamlining your XR development workflow. Android XR Engine Hub serves as your centralized mission control, managing device connections, runtime configurations, and streaming tools across multiple game engines.

### Key features

[![](https://developer.android.com/static/images/develop/xr/engine-hub/direct-preview-192px.svg)](https://developer.android.com/develop/xr/engine-hub/direct-preview)

### [Direct Preview](https://developer.android.com/develop/xr/engine-hub/direct-preview)

Direct Preview lets you test and iterate on complex interactions directly inside your game engine's editor using live data from the Android XR Device. This completely bypasses the usual, time-consuming build-and-deploy cycle within XR development.

[Set up Direct Preview](https://developer.android.com/develop/xr/engine-hub/direct-preview)

![](https://developer.android.com/static/images/picto-icons/improve-performance.svg)

### Performance tracing & analysis

Capture high-frequency performance traces directly from the Engine Hub and visualize them instantly in the Perfetto Web UI.

* **Perfetto integration:** Record detailed performance traces directly from the dedicated Performance page using on-screen device recording controls.
* **Automated visualization:** Automatically open captured traces in the Perfetto Web UI with pre-configured viewport parameters (`visStart` and `visEnd`) for immediate analysis.
* **Trace file management:** Save performance trace captures to a default output directory, with quick “Open File” shortcuts for fast file location.

![](https://developer.android.com/static/images/picto-icons/brackets.svg)

### Device logcat streaming

Stream, inspect, and filter device logcat messages in real time with dedicated window controls and smart search.

* **Standalone window:** Pop out the logcat viewer into a separate, resizable desktop window to support multi-monitor development setups.
* **Smart keyword filtering:** Filter log streams using case-insensitive searches matching both log tags and message content.
* **Embedded logcat dashboard:** Monitor live device output directly within the Engine Hub or filter logs with dedicated search controls.

![](https://developer.android.com/static/images/picto-icons/cast.svg)

### Screencasting

Mirror your Android XR device screen directly to your workstation in real time with high resolution and low latency.

* **Low-latency mirroring:** Stream real-time device visuals into a resizable desktop sub-window powered by an integrated scrcpy backend.
* **Interactive casting controls:** Start and stop screencasting sessions with a single click directly from the Engine Hub interface.

![](https://developer.android.com/static/images/picto-icons/text-images.svg)

### Screenshot & screen recording

Capture screenshots and record video of your connected XR device display with a single click. Media is automatically saved and immediately opened in your default viewer for instant inspection.

![](https://developer.android.com/static/images/picto-icons/tools-2.svg)

### Remote configuration

Configure device settings, debug toggles, and runtime performance overlays directly from the desktop interface.

* **Performance Insight:** Enable or disable real-time on-device performance metric overlays (`toggle_xr_perf_metrics`) with a single click.
