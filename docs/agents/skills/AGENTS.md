## Purpose of this Directory

This directory (`//depot/google3/third_party/devsite/android/en/agents/skills`)
hosts Android agent skills published on `developer.android.com` (DAC) and
exported to the open-standard GitHub skills repository. All authors and AI
agents must consult the `create-update-audit-android-skill` skill before
creating, updating, auditing, packaging, or converting skills in this directory.
