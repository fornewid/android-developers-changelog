Android capabilities


Operating alongside your coding agent, Android CLI provides a unified interface for
interacting with Android tools, devices, workflows, skills and up-to-date platform
guidelines. You can execute these same commands seamlessly from terminal sessions,
automated scripts, or CI pipelines.

## Essential commands in a single interface

[Download Android CLI](https://developer.android.com/tools/agents/android-cli/download) ![](http://developer.android.com/static/images/picto-icons/frame.svg)

### Capture what's on screen

Use screen capture --annotate to capture the running app and label detected UI elements for developers and agents to inspect. ![](http://developer.android.com/static/images/picto-icons/layout.svg)

### Debug layouts

Use android layout to return the active app's layout tree as JSON from a connected physical device or emulator. ![](http://developer.android.com/static/images/logos/android-studio.svg)

### Bring Android Studio analysis to the terminal

Access file analysis, declaration lookup, usage discovery, and Compose preview rendering from the command line. ![](http://developer.android.com/static/images/picto-icons/hardware.svg)

### Manage Virtual Devices

Create, manage, and run Android Virtual Devices or connect via Android Device Streaming directly from your terminal.
