# Gemini 3 is now available for AI assistance in Android Studio

1 min read ![](https://developer.android.com/static/blog/assets/gemini3as_Assitance_a5fd86cee5_ZfNyVb.webp) 18 Nov 2025 [![View Tor Norbye's profile](https://developer.android.com/static/blog/assets/Tor_Norbye_7b1b17eb31_Z1JVx8k.webp)](https://developer.android.com/blog/authors/tor-norbye.md.txt) [Tor Norbye](https://developer.android.com/blog/authors/tor-norbye.md.txt) Senior Director of Engineering [The Gemini 3 Pro model](https://blog.google/technology/developers/gemini-3-developers), released today and engineered for better coding and agentic experiences, is now available for AI assistance in the latest version of Android Studio Otter. [Android Studio](https://developer.android.com/studio) is the best place for professional Android developers to use Gemini 3 for superior performance in [Agent Mode](https://developer.android.com/studio/gemini/agent-mode.md.txt), streamlined development workflows, and advanced problem solving capabilities. With [agentic AI assistance](https://developer.android.com/gemini-in-android) to help you with boilerplate and complex development tasks, Android Studio helps you focus on what you do best---creating high quality apps for your users.

To get started with Gemini 3 Pro for Android development, download or update to the latest version of Android Studio Otter. For developers using Gemini in Android Studio at no-cost (Default Model), we are rolling out limited access to Gemini 3 with a 1 million token size window. For higher usage rate limits and longer sessions with Agent Mode, [use a Gemini API key](https://developer.android.com/studio/gemini/add-api-key.md.txt) to leverage Gemini 3 in Android Studio for the highest tier of AI capability.
![geminiapi.png](https://developer.android.com/static/blog/assets/geminiapi_5d640db84b_1qf4ri.webp)

*Adding a Gemini API key in Android Studio*

This week we're rolling out Gemini 3 access for organizations, starting with users who have Gemini Code Assist Enterprise licenses. Your[IT administrator will need to enable access](https://developers.google.com/gemini-code-assist/docs/configure-release-channels) to preview models through the Google Cloud console, and you'll need to sign up for [the waitlist](https://docs.google.com/forms/d/e/1FAIpQLScQBMmnXxIYDnZhPtTP3xr5IwHNzKW4nLomuQ1tGOO-UldMdQ/viewform).

Try Gemini 3 Pro in Android Studio, and let us and the Android developer community know what you think. You can follow us across [LinkedIn](https://www.google.com/search?q=https://www.linkedin.com/company/android-developers/), [Blog](https://android-developers.googleblog.com/), [YouTube](https://www.youtube.com/user/androiddevelopers), and[X](https://x.com/AndroidDev). We can't wait to see what you build!
