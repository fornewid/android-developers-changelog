# Powering Seamless Player Sign-In: Introducing the Open-Source Sign in with Google Plugin for Unity

1 min read ![](https://developer.android.com/static/blog/assets/ABL_Sign_in_with_Google_Plugin_for_Unity_Gaming_DESIGN_Header_and_metadata_V01_26433b75fe_Z260GOa.webp) 10 Nov 2026 [![View Michelle Martin's profile](https://developer.android.com/static/blog/assets/unnamed_29_8358471ffe_MSkhy.webp)](https://developer.android.com/blog/authors/michelle-martin.md.txt) [Michelle Martin](https://developer.android.com/blog/authors/michelle-martin.md.txt) Sr. Solutions Consultant, Users and Products, Core 3P identity With Unity powering over half of all mobile titles worldwide, first impressions matter. For game developers, a smooth, reliable player onboarding experience is essential to driving day-one retention and long-term engagement. Yet for years, developers looking to integrate Google authentication into Unity games often relied on deprecated sample bridges that struggled with modern Gradle build pipelines and AndroidX requirements.

Today, we are thrilled to announce the launch of the Sign in with Google Mobile Plugin for Unity, now open-source and publicly available on [GitHub.](https://github.com/googlesamples/siwg-mobile-unity-plugin)

Built specifically with modern engine requirements in mind---including full compatibility with Unity 6.5---this production-ready plugin replaces the legacy implementation with a first-party, high-performance authentication bridge.

### Key Highlights for Game Developers

- Streamlined Native Performance: By implementing lightweight, native-only bridges, the plugin minimizes runtime overhead, removes legacy baggage, and ensures predictable, responsive sign-in interactions across devices.
- Modern Security Standards: Integrates directly with Android's modern Credential Manager (Kotlin) and iOS's GIDSignIn (Objective-C++), giving players a fast, passwordless login experience while ensuring compliance with platform-level privacy and security standards.
- Editor-Integrated Configuration: Developers can configure their Web Client ID and iOS Reversed Client ID directly inside the engine editor via Window \> Google Sign-In Native \> Settings---eliminating messy manual manifest edits.
- Decoupled \& Backend-Agnostic: Rather than locking developers into a single backend stack, the plugin retrieves a signed Google ID Token (idToken) directly into your C# scripts via event callbacks. You can seamlessly hand off tokens to various Back end as a Service platforms, such as Firebase Authentication, Supabase, Auth0, etc... , or your own user management platform .
- Frictionless Setup: Integrate the plugin easily by downloading the pre-built .unitypackage

Whether you are an indie game developer prototyping your first title or an established studio optimizing player onboarding for your next global launch on Unity 6.5, getting started takes just minutes:

👉 Explore the Sign in with Google Plugin for Unity on the [GitHub repository](https://github.com/googlesamples/siwg-mobile-unity-plugin)
