# Mastering on-device intelligence with ML Kit and LiteRT in Google Play services - Speakers: Chintan Parikh (Lead Product Manager), Fergus Henderson (Staff Software Engineer) - Track: Intelligent Apps - Video: https://www.youtube.com/watch?v=LiBWWJ9IKag - Page: https://developer.android.com/events/dev-summit/talks/mastering-on-device-intelligence-with-ml-kit-and-litert-in-google-play-services ## About the talk Stop choosing between plug-and-play AI convenience and custom model flexibility---you can deploy both in a single, ultra-lean app without adding megabytes of binary bloat. In this session, we'll demonstrate how to build this exact dual-stack architecture in a single Android app. You'll see how to leverage ML Kit for ready-to-use classical ML tasks (like doc scan) alongside LiteRT standalone in Play services for your custom computer vision or audio workloads. We'll dive deep into how both implementation paths unite under the hood to utilize the modern LiteRT runtime, giving your app seamless, hardware-accelerated performance on CPU and GPUs with a virtually zero-byte download footprint. Key takeaways for developers: -Uncompromised performance: Both turnkey and custom models are hardware-accelerated automatically using the unified CompiledModel API. -Micro-APKs: Dramatically reduce your app's download size by offloading both the ML Kit and LiteRT runtimes to Play services. -Hybrid integration: Master running multiple ML workflows side-by-side in production without resource conflicts. ## Summary - LiteRT in Google Play services shares one maintained runtime across apps to reduce APK sizes by about 8 MB. - Turnkey ML Kit features and custom LiteRT models can run together in a single application on the same runtime. - The CompiledModel API simplifies GPU acceleration and delivers up to 1.4x faster performance than legacy TFLite GPU inference. - Platform availability extends beyond phones to Wear OS 4 or later and Android Automotive OS on Android 11 or later. - Adopting LiteRT in Google Play services involves updating Maven dependencies to \`play-services-litert\`, calling \`LiteRt.initialize\` to obtain an environment, and passing it to \`CompiledModel.create\`. - Migrating to the 2.x CompiledModel API is recommended because 1.x is in maintenance mode and NNAPI is going away. ## Skills - \[Android LiteRT skill\](https://github.com/android/skills/tree/main/device-ai/litert/) ## Resources - \[Docs \& samples\](https://developers.google.com/edge/litert/android) ## Topics on-device-ai, ml-kit, litert, google-play-services, gpu-acceleration, machine-learning ## Transcript ### Introduction and
