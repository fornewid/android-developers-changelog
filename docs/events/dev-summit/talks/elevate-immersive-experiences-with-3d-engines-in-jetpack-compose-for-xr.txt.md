# Elevate immersive experiences with 3D Engines in Jetpack Compose for XR - Speakers: Luke Hopkins (Android XR Developer Relations Engineer), Joshua Lorett (Android Staff Engineer), Rodrigo Sanchez (Software Developer - Beyond Sports) - Track: Android XR - Video: https://www.youtube.com/watch?v=u8dsUtPvOlY - Page: https://developer.android.com/events/dev-summit/talks/elevate-immersive-experiences-with-3d-engines-in-jetpack-compose-for-xr ## About the talk Learn how to integrate 3D game engines (Godot \& Unity) with Jetpack Compose into a single codebase for mobile and Android XR. We'll explore embedding 3D scenes into spatial containers, setting up Kotlin-to-engine communication ---featuring an exclusive look into how the NBA built their live basketball experience on Android XR. ## Summary - The OpenXR Spatial Containers extension allows 3D engines to share space with native Android UI. Instead of taking over the skybox, real-time engines run inside a managed 3D volume alongside Jetpack XR spatial panels. - Developers can embed real-time engines directly into Jetpack Compose applications as AAR libraries. This approach lets native Android handle business logic and UI while the engine renders 3D components. - Embedding Godot requires an AAR dependency and an AAPT build rule to keep hidden assets. A \`GodotPlugin\` subclass then handles bidirectional communication with Kotlin. - Compose UI loops must stay decoupled from continuous engine tick loops. Blindly forwarding engine updates triggers constant recomposition and causes UI lag. - The NBA app integrates Unity as an embedded library in a separate process using AIDL for inter-process communication, protecting the host app from crashes. ## Resources - \[Android XR developer documentation\](https://developer.android.com/develop/xr) ## Topics android-xr, jetpack-compose,
