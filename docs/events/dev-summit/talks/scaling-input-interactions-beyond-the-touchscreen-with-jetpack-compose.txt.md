# Scaling input interactions beyond the touchscreen with Jetpack Compose - Speakers: Alex Vanyo (Software Engineer), Jeremy Walker (Compose Software Engineer) - Track: Apps foundation - Video: https://www.youtube.com/watch?v=iztM_PgoCjw - Page: https://developer.android.com/events/dev-summit/talks/scaling-input-interactions-beyond-the-touchscreen-with-jetpack-compose ## About the talk As new form factors move beyond the touchscreen, Compose's input system has evolved to meet the challenge. Its layered architecture provides the foundation for supporting everything from advanced trackpad gestures to novel hardware inputs seamlessly. Through clear architectural breakdowns and hands-on code examples, follow the lifecycle of an input event all the way from the OS platform layer up to Compose gesture detectors and UI components. You will discover how to trace events across the entire stack, apply key architectural patterns for emerging input types, and confidently debug complex gesture interactions in your own apps. ## Summary - Jetpack Compose processes incoming Android pointer events through a six-phase pipeline. This pipeline maintains a hit path tree and dispatches events in three passes across UI nodes. - Trackpad inputs in Compose now map to mouse events instead of touch. Compose also converts platform fake finger events into dedicated pan and scale pointer events. - Intelligent eyewear trackpads introduce indirect input types rather than screen coordinate touches. They use a Primary Directional Motion Axis to map horizontal swipes into vertical next or previous navigation. - Testing support has expanded beyond touch with new methods such as \`performTrackpadInput\`. These APIs provide familiar testing surfaces to validate that apps handle non-touch devices correctly. ## Topics jetpack-compose, pointer-input, trackpads, gestures, intelligent-eyewear, accessibility
