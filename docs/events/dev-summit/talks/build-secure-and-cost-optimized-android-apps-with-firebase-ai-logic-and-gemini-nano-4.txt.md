# Build secure and cost-optimized Android Apps with Firebase AI Logic and Gemini Nano 4 - Speakers: Ankita Saxena (Product Manager), Arthur Thompson (Developer Relations Engineer) - Track: Intelligent Apps - Video: https://www.youtube.com/watch?v=IPKerNnpddQ - Page: https://developer.android.com/events/dev-summit/talks/build-secure-and-cost-optimized-android-apps-with-firebase-ai-logic-and-gemini-nano-4 ## About the talk Building production-ready generative AI into Android apps requires more than connecting to an LLM---it demands enterprise-grade security and cost controls. In this session, discover how Firebase AI Logic empowers developers to deploy secure, budget-conscious AI experiences at scale. We will cover from security foundations and Firebase App Check, cost management, dynamic model routing to leveraging the multimodal capabilities. ## Summary - Firebase AI Logic routes requests from client SDKs directly to Gemini APIs without a custom back end. Server prompt templates store prompts in the cloud to avoid app updates. - Firebase App Check protects resources against abuse by ensuring requests originate from your app. It integrates attestation providers like Play Integrity and reCAPTCHA Enterprise before you enforce checks. - Gemini Nano 4 executes on-device inference to lower latency and safeguard user privacy. Firebase AI Logic manages fallback routing to the cloud when needed. - Spend caps and Firebase AI Logic triggers keep cloud costs predictable. Firebase automatically pauses your AI service at 100% spend, and triggers let you run custom functions before or after generation. - Gemini Live API powers bidirectional conversational audio and video streaming. The client SDK manages the underlying WebSocket connections and streaming protocols. ## Topics firebase-ai-logic, gemini-nano, firebase-app-check, on-device-ai, cost-optimization, gemini-live-api ##
