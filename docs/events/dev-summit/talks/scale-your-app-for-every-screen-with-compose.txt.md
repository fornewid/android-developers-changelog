# Scale your app for every screen with Compose - Speakers: Francesco Romano (Senior Developer Relations Engineer) - Track: Apps foundation - Video: https://www.youtube.com/watch?v=SGTkTKX7qq4 - Page: https://developer.android.com/events/dev-summit/talks/scale-your-app-for-every-screen-with-compose ## About the talk The Android ecosystem is vast, with users shifting seamlessly across phones, tablets, foldables, and desktop environments. Now that we are Compose First, this session explores how to architect your app for resizable windows and diverse aspect ratios---where traditional layout assumptions break down, leading to stretched UIs and lost state. Explore how the latest capabilities in Jetpack Compose, Navigation 3, and WindowManager can help you build dynamic layouts that naturally scale from compact screens to dual-pane displays. Walk away with strategies to accelerate your development workflow using Gemini and our skills, like the adaptive skill, to automatically refactor legacy codebases for larger screens. ## Summary - Android platforms require adaptive apps because the system ignores orientation and aspect ratio locks on larger screens starting in Android 16, with manifest opt-outs removed in Android 17. - The experimental \`MediaQuery\` API declaratively tracks active UI capabilities such as window size and folding postures. It replaces stitching together multiple legacy platform managers into Compose state. - Stable \`Grid\` and \`FlexBox\` primitives provide adaptive layout building blocks. \`Grid\` enables parameterized multi-dimensional arrangements within a single composable, while \`FlexBox\` provides one-dimensional space distribution and wrapping. - Jetpack Navigation 3 structures app-level multi-pane flows around state and scenes. Custom scene strategies evaluate UI capabilities and window size classes to dynamically switch between single-pane and multi-pane presentations. - Compose Adaptive skills for Gemini automate app migrations to modern responsive components. The updated skill refactors layouts, resolves state loss bugs, and configures desktop inputs such as keyboard shortcuts and cursors. ## Resources - \[Install Android CLI\](https://goo.gle/android-cli)
