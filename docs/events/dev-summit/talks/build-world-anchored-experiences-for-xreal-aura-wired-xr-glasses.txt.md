# Build world anchored experiences for wired XR glasses - Speakers: Yasmine Quintana Evjen (Senior Product Manager), Dereck Bridie (Developer Relations Engineer), Paul Hoover (Senior Interaction Designer) - Track: Android XR - Video: https://www.youtube.com/watch?v=4NGBZnfnD6o - Page: https://developer.android.com/events/dev-summit/talks/build-world-anchored-experiences-for-xreal-aura-wired-xr-glasses ## About the talk Go beyond screen-space and anchor your apps in the real world with Android XR. This session teaches you how to build geospatially aware Android XR experiences using Jetpack Compose Glimmer and ARCore's Geospatial API. We will start by covering how to get a device's geospatial pose with ARCore. Then, you'll see how Glimmer's minimal UI components can be anchored to real-world locations via the Visual Positioning System (VPS). We'll combine these to build a simple, location-aware spatial experience. ## Summary - Android XR brings digital experiences into physical environments across a spectrum of devices, from intelligent eyewear to wired XR glasses. Existing 2D Android-compatible apps work on XR headsets and wired XR glasses with minimal modifications. - Jetpack Compose Glimmer provides components and styles tailored for optical see-through displays. Built-in helper functions adjust brand colors to glasses-safe shades to maintain visibility and contrast across lighting conditions. - The Glimmer library adds new components such as pagers and button groups. A depth API helps separate stacked elements on see-through displays where black is transparent. - Subspace composables place interfaces in 3D space and can follow ARCore anchors via a follow target, such as a tracked QR code. - The Geospatial API in ARCore combines Street View data and GPS measurements to position devices accurately in supported areas. You can attach Glimmer components to real-world geospatial anchors using coordinates from Places API queries. ## Resources - \[Android CLI\](https://goo.gle/android-cli) - \[Glimmer
