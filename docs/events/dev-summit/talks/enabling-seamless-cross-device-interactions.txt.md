# Enabling seamless cross-device interactions - Speakers: Yacine Rezgui (Developer Relations Engineer), Hanrui Gao (Developer Relations Engineer), Nataraj K R (Developer Relations Engineer) - Track: Apps foundation - Video: https://www.youtube.com/watch?v=2-EfHHa_NxE - Page: https://developer.android.com/events/dev-summit/talks/enabling-seamless-cross-device-interactions ## About the talk As users move between phones, wearables, and audio peripherals, delivering fluid cross-device experiences has become essential for engagement. However, relying on standard networking approaches often leads to battery drain, latency spikes, and fragmented user sessions. This deep dive introduces specialized Android APIs built for multi-device communication, offering memory- and power-efficient patterns to keep transitions between devices instant, reliable, and intuitive. ## Summary - Companion Device Manager replaces foreground services for Bluetooth peripherals by waking apps based on presence and managing connections without draining battery. Android 17 adds new profiles specifically for medical devices and fitness trackers. - Jetpack Telecom acts as a system call coordinator for VoIP apps across connected devices like watches and cars, working back to Android 8. It also synchronizes mute and hangup actions via CallControlScope. - Upcoming Jetpack Telecom 1.1.0 features include unified call histories in the system dialer (SDK 36.1+) and automatic 5G network slicing on supported carrier networks. - Quick Share SDK is launching next year so developers can embed local, end-to-end encrypted file sharing directly into Android and iOS apps. Tap to share (launched with Pixel 11) can even automatically wake a closed receiving app. ## Resources - \[Devices per person in 2023 chart\](https://www.statista.com/chart/32691/average-number-of-devices-and-connections-per-capita/) ## Topics cross-device, companion-device-manager, jetpack-telecom, quick-share, bluetooth, voip,
