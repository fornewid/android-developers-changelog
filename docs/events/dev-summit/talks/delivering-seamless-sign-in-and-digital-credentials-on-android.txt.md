# Delivering seamless sign in and digital credentials on Android - Speakers: Chiping Yeh (Developer Relations Engineer), Tom Colvin (CTO, Apptaura) - Track: Apps foundation - Video: https://www.youtube.com/watch?v=YqdfIR7NUl0 - Page: https://developer.android.com/events/dev-summit/talks/delivering-seamless-sign-in-and-digital-credentials-on-android ## About the talk As the industry moves away from passwords and physical wallets, delivering a modern user journey demands both seamless authentication and trusted identity verification. While passkeys establish secure one tap logins, switching devices remains one of the largest drop off points in user engagement. Learn how to reduce migration friction using the Restore Credentials API to meet the new Google Play Zero Tap Sign In standard. This session explores how a single integration with Android Credential Manager unifies passkeys, silent device restoration, and Digital Credentials, allowing you to verify identity attributes directly from the device and build an effortless, secure onboarding flow. ## Summary - Jetpack Credential Manager provides a unified API for passkeys and passwords. It handles the authentication interface and cryptographic operations without developers needing to write UI code. - Conditional Create lets apps upgrade password users to passkeys silently in the background after a successful password autofill. This opportunistically generates and stores a passkey without interrupting the user. - Google Play will require zero-tap sign-in by April 2027 to maintain full publishing capabilities. Apps can meet this requirement by generating a restore key using the Restore Credentials API. - The Digital Credentials API coordinates exchanges between credential holders and verifiers. Holders retain sharing control, while credential payloads stay end-to-end encrypted and inaccessible to Google. - Email and phone number verification replace one-time passwords and magic links with verified digital credentials. Users give consent directly in the Credential Manager bottom sheet without leaving your app. ## Skills - \[Restore Credentials skill\](https://goo.gle/restore-credentials-skill) ## Resources -
