# Integrate your app with the Android intelligence system - Speakers: Sarah Shamsie (Product Manager at Google), Dan Galpin (Developer Relations Engineer) - Track: Intelligent Apps - Video: https://www.youtube.com/watch?v=UsqDEfyOH2E - Page: https://developer.android.com/events/dev-summit/talks/integrate-your-app-with-the-android-intelligence-system ## About the talk Android is evolving into an intelligence system where agents like Gemini orchestrate tasks across apps. To unlock new user experiences and participate in these agentic workflows, your app must expose its core capabilities. This session is a practical guide to integrating your app with Android's intelligence layer. We'll survey key integration paths - including on-device Android MCP, server-side MCP, and Task Automation - and provide a decision framework for choosing the right path for your use case. We'll also explore proactive experiences with Personal Context. You will learn how to: - Select the optimal integration path for your app's needs. - Implement both reactive and proactive intelligence features. - Balance performance and security in agentic integrations. ## Summary - Android MCP is a unified on-device tool calling framework powered by the Jetpack AppFunctions library. It maps MCP primitives to Kotlin constructs and runs on Android Binder IPC. - On-device tools excel when accessing encrypted data or device sensors. Alternatively, platform-driven Task Automation lets pre-loaded agents simulate touch events without code changes. - Your app acts as an Android MCP server while agents discover and call tools. Declare tools with \`AppFunctionDeclaration\`, provide KDoc descriptions, and avoid relying on Kotlin default values. - The Connected Apps Platform, currently in preview, lets you test your AppFunctions with Gemini. Set up your connected app in Google Connected Console, then upload your bundle in Play Console. ## Resources - \[Jetpacker travel sample app\](https://goo.gle/jetpacker) - \[Sample agent source
