# Agentic coding: A roundtable with industry leaders - Speakers: Luis Artola (Engineering Manager), Ty Smith (Principal Engineer), Vinay Gaba (Senior Engineering Manager, Databricks), Kaushik Gopal (Principal Software Engineer), Annyce Davis (Sr. Director of Engineering), Ben Trengrove (Developer Relations Engineer) - Track: Tools \& Performance - Video: https://www.youtube.com/watch?v=megAzvXTdrc - Page: https://developer.android.com/events/dev-summit/talks/agentic-coding-a-roundtable-with-industry-leaders ## About the talk As AI tools rapidly reshape modern software engineering, this panel will explore how developers are leveraging AI-assisted coding, automated agents and specialized developer tooling in their daily workflows. We aim to highlight practical applications, discuss measurable productivity improvements and candidly address the challenges engineering teams face when integrating AI at scale. Moderated by Ben Trengrove, Google Developer Relations Engineer ## Summary - AI tools accelerate code writing and PR creation, but teams face friction in downstream stages like code review and business approvals. - Code reviews are shifting from manual line-by-line checks toward agent-assisted verification and intent reviews. - CI infrastructure faces severe compute scaling challenges from rising code volumes, prompting investments in remote build execution and caching with Bazel. - Enterprises manage AI token costs with usage limits and automated model routing. ## Topics
