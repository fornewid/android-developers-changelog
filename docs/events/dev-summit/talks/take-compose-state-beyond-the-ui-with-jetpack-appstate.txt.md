# Take Compose state beyond the UI with Jetpack AppState - Speakers: Ben Sagmoe (Developer Relations Engineer), Elif Bilgin Morris (Software Engineer) - Track: Apps foundation - Video: https://www.youtube.com/watch?v=69QYEXymfVo - Page: https://developer.android.com/events/dev-summit/talks/take-compose-state-beyond-the-ui-with-jetpack-appstate ## About the talk Compose's snapshot runtime, automatic dependency tracking, and atomic updates don't have to stop at the UI layer. Jetpack AppState lets you move Compose state upstream---streamlining what reaches your screens by hoisting and deriving state with the snapshot system before it ever hits the UI. In this session, you'll learn about AppState's two foundational libraries. We'll dive into StateStore for hoisting state, and Transform for using composition to derive state with plain Kotlin control flow---eliminating complex Flow combine chains and keeping your UI effortlessly in sync. ## Summary - Compose Runtime works as a general-purpose state management engine without Compose UI. Its snapshot system tracks reads dynamically and keeps concurrent updates consistent across properties. - Jetpack AppState Transform computes and exposes Compose State from headless composable blocks. It replaces complex Flow operator chains like \`combine\` while supporting early returns and nested state derivations. - Transform uses an eager headless frame clock to run transformations off the UI thread. The clock parks whenever watched states remain unchanged, avoiding wasted work. - Jetpack AppState StateStore shares Compose State across distinct components like activities and background services. Integrating it with DataStore lets individual keys survive process death without custom boilerplate. ## Resources - \[Molecule library on GitHub\](https://github.com/cashapp/molecule) - \[AppState documentation\](https://goo.gle/appstate-docs) - \[AppState Recipes repository on GitHub\](https://www.github.com/android/appstate-recipes) ## Topics jetpack-compose, jetpack-appstate,
