# What's new in Android dev tools - Speakers: Esteban de la Canal (Software Engineer), Adarsh Fernando (Group Product Manager) - Track: Tools \& Performance - Video: https://www.youtube.com/watch?v=w-auFZP5gJo - Page: https://developer.android.com/events/dev-summit/talks/whats-new-in-android-dev-tools ## About the talk Discover what's next for Android development across Android Studio and the terminal with Android CLI. In this session, we unveil the latest in Android Studio Canary and Stable---from AI-assisted code migrations to Compose and Agent Client Protocol (ACP) support, to Lightbuild's declarative architecture. We'll also dive into the latest updates to the Android CLI toolchain. Learn how you can use it to automate your inner-loop workflows with improved access to devices, diagnostics tools for local and production issues, profiling workflows that let your agents test and validate optimizations and much more. ## Summary - Android CLI provides structured, predictable commands without interactive prompts, built specifically to help modern coding agents navigate developer workflows. - New Android CLI commands let agents render Compose previews without Android Studio and inspect production crashes from Crashlytics. They can also delta-push APK updates during installation. - Native Android x86 APK execution directly on Linux desktops runs apps as single processes with Logcat output and without nested virtualization. - Official Android plugins equip agents in Google Antigravity and Claude Code with Android CLI and architectural guidelines. Antigravity can view Compose previews and interact directly with devices. - Android Studio Rabbit 2 introduces Bring Your Own Agent and AI Change Review to inspect pull requests and fix issues. ## Resources - \[Android Studio download\](https://d.android.com/studio) - \[Android CLI feedback and downloads\](https://d.android.com/cli) ## Topics android-cli, ai-agents, android-studio,
