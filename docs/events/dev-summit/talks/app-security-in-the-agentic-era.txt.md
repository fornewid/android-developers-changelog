# App security in the agentic era - Speakers: Kristen O'Leary (Senior Developer Relations Engineer), Sabs (Developer Relations Engineer) - Track: Tools \& Performance - Video: https://www.youtube.com/watch?v=2eof3mvB-yY - Page: https://developer.android.com/events/dev-summit/talks/app-security-in-the-agentic-era ## About the talk This presentation explores the strategic shift from viewing AI as a generic coding assistant to leveraging it as a context-aware, automated security peer reviewer integrated directly into the Android development lifecycle. We discuss how specialized AI agents, connected to the Android toolchain via skills, can help improve app security. By bridging the gap between raw LLM capabilities and deep project context, this approach empowers development teams to maintain high-velocity feature delivery without compromising rigorous security and policy standards. ## Summary - Generic AI agents miss key context during audits, but Android security skills provide researcher-backed guidance. They check intent security and enforce permissions using project-specific build configurations. - The Play policy skill runs static analysis to catch compliance issues before submission. It can cross-reference code analysis against existing Play Store declarations. - The Play Integrity API evaluates app and device integrity at runtime. The Protected with Play dashboard unites integrity and distribution monitoring in one place. - Targeted APIs allow apps to protect user privacy without requesting broad permissions. Examples include the SMS Retriever API and the alpha Location Button library. ## Skills - \[Android CLI and Android skills\](https://goo.gle/android-cli) ## Resources - \[Google Bug Hunters key
