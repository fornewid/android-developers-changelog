# Evolving Tiles to Wear Widgets using Jetpack Glance and Remote Compose - Speakers: François Deschênes (Product Manager), Yuri Schimke (Software Engineer) - Track: Apps foundation - Video: https://www.youtube.com/watch?v=5--1viVciq4 - Page: https://developer.android.com/events/dev-summit/talks/evolving-tiles-to-wear-widgets-using-jetpack-glance-and-remote-compose ## About the talk In this session, we will take a technical deep dive into the evolution from full-screen Tiles to dynamic, partial-height Wear Widgets. We will explore the technical benefits of the unified Jetpack Glance API and the new Remote Compose engine, detailing how they seamlessly align with Modern Android Development. Finally, we will share the latest UX guidance and walk through practical migration strategies to help you build the next generation of glanceable UI. ## Summary - Wear OS is evolving full-screen Tiles into Wear Widgets built with Jetpack Glance and powered by Remote Compose. - Remote Compose shares the same compiler and runtime as Jetpack Compose UI while safely decoupling your UI from the app process. - Small and large container sizes align with mobile grid formats, while Jetpack Glance Wear APIs maintain backward compatibility down to Wear 4. - Migrating existing Tiles to widgets can use either a recommended dual-service strategy or a single compatibility service. ## Skills - \[Tiles to widgets migration skill\](https://goo.gle/skills-repo) ## Resources - \[Tile to widget service migration\](https://goo.gle/wearos-tiles-widgets-migration) - \[Horologist media sample app\](https://goo.gle/media-sample) - \[Wear Widgets getting started guide\](https://goo.gle/wear-widgets) ##
