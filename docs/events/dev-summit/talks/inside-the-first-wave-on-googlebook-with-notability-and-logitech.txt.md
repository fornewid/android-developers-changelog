# Inside the first wave on Googlebook with Notability and Logitech - Speakers: Emilie Roberts (Developer Relations Engineer), Ryan Shea (Head of Android), Joe Yezhou Wang (Engineering manager at Logitech) - Track: Apps foundation - Video: https://www.youtube.com/watch?v=aZjbDY3UXws - Page: https://developer.android.com/events/dev-summit/talks/inside-the-first-wave-on-googlebook-with-notability-and-logitech ## About the talk The launch of Googlebook opens up a new frontier for high-fidelity, desktop-grade experiences. In this session, we go behind the scenes with two pioneering partners who built for this platform from the ground up. Notability will share their journey creating a desktop-class Android app using Jetpack Compose. Learn about their journey moving from other app platforms with desktop top-of-mind. Second, Logitech will dive into the hardware side, discussing how they are building and customizing peripherals to integrate seamlessly with Googlebook. Join the session to get practical, real-world insights on optimizing inputs, leveraging large-screen APIs, and delivering a premium, cohesive user experience across hardware and software. ## Summary - Jetpack Compose and Navigation 3 make it easy to adapt layouts across devices based on available window size rather than device form factors. - Desktop-class experiences require supporting multi-input models such as keyboards and trackpads. Features like Continue On in Android 17 also let users hand off tasks between devices. - Jetpack Ink gives developers a low-latency drawing pipeline without having to manage custom rendering threads or complex layer handoffs. - The allowlisted Peripheral Customization API lets developers map peripheral hardware triggers to OS actions using vendor and product IDs. ## Topics googlebook, jetpack-compose, jetpack-ink, navigation-3, large-screens, peripheral-customization, kotlin-multiplatform ## Transcript ### Introduction to building for Googlebook
