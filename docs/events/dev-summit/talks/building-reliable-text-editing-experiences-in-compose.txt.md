# Building reliable text editing experiences in Compose - Speakers: Anastasia Soboleva (Software engineer), Haoyu Zhang (Senior Software Engineer) - Track: Apps foundation - Video: https://www.youtube.com/watch?v=1DvjkRYGs2g - Page: https://developer.android.com/events/dev-summit/talks/building-reliable-text-editing-experiences-in-compose ## About the talk The journey to reliable text editing in Compose culminated in the complete rewrite of BasicTextField. This shift to a buffer-driven architecture eliminated IME race conditions once and for all. This session unpacks why legacy input syncing had to go and how TextFieldState keeps keyboard updates in sync. From there, take a deep dive into formatted editing to explore the mechanics of TrackedRange, the performance costs of edit blocks, and the real-world catches behind style boundaries, before taking an early peek at Markdown rendering. ## Summary - The \`TextFieldState\` API overload replaces the callback-based overloads in Compose. It updates synchronously with user typing, eliminating timing issues with software keyboards and unnecessary recompositions. - Input and output transformations let you manipulate text using \`TextFieldBuffer\`. You can intercept edits before committing them or format display text without manually computing offset mappings. - Hoisting \`TextFieldState\` depends on your architecture needs. You can keep it locally in a composable or store it directly in a \`ViewModel\` for business logic access. - Compose 1.12 adds formatted text editing APIs to \`TextFieldBuffer\`. You can apply styles with customizable \`ExpandPolicy\` options, and existing style ranges update automatically as users edit. - A new markup text library for Jetpack Compose is currently in development. It supports formats like Markdown with incremental parsing and rendering for live editing and streaming. ## Resources - \[Migration guide to TextFieldState\](https://goo.gle/migrate_to_state_textfield) ## Topics jetpack-compose, textfieldstate, text-editing, basictextfield, formatted-text, input-transformation ## Transcript ###
