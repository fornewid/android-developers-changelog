# Architecting Spatial Content on Android XR with Unity - Speakers: Levana Chen (Software Engineer), Jennifer Stanton (Senior Software Engineer) - Track: Android XR - Video: https://www.youtube.com/watch?v=bz_01jWmNZc - Page: https://developer.android.com/events/dev-summit/talks/architecting-spatial-content-on-android-xr-with-unity ## About the talk Discover how to anchor and persist 3D experiences in the real world using Unity and Android XR. This session covers the Spatial Entities framework, Cloud Anchors, and Geospatial APIs, demonstrating how to build context-aware apps that remember physical placements and sync multi-user spatial data across sessions. We will examine the architecture behind spatial entities, understand how to anchor digital assets to physical objects, surfaces, and geographic locations. You will walk away with practical Unity workflows for mapping spaces, persisting content across sessions, and creating shared, location-aware AR/XR experiences. ## Summary - AR Foundation provides a unified scripting API across XR platforms using OpenXR extensions. It lets you represent and query real-world features such as planes and meshes. - Persistent anchors stabilize digital content across sessions and device restarts. You can persist them with \`TrySaveAnchorAsync\` and reload them using serialized GUIDs. - The Spatial Entities framework replaces trackable extensions to provide cross-platform support and better performance for tracking items like bounding boxes and markers. - Manager components should be disabled until Android XR permissions are granted. This avoids subsystem initialization failures caused by restricted access to sensitive environment data. - The Geospatial API uses Google Cloud ARCore services and VPS to position content at real-world outdoor locations. ## Resources - \[Unity Roadmap\](https://unity.com/roadmap) - \[AR Foundation Samples\](https://github.com/unity-technologies/arfoundation-samples) - \[Android XR with
