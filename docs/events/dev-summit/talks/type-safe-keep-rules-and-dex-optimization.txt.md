# Type safe keep rules and DEX optimization - Speakers: Chris Craik (Android Performance Engineer), Breana Tate (Developer Relations Engineer) - Track: Tools \& Performance - Video: https://www.youtube.com/watch?v=bwlRxGJMzWs - Page: https://developer.android.com/events/dev-summit/talks/type-safe-keep-rules-and-dex-optimization ## About the talk Android apps often ship under-optimized due to overly conservative keep rules often from third-party libraries, leading to bloated APKs, slower cold starts, and degraded runtime performance. With Google Play's new performance thresholds for DEX optimization, app visibility now directly depends on staying ahead of the optimization curve. This talk introduces a modern R8 workflow to tackle rule bloat. You will learn to: - Use the R8 config analyzer and skill to identify legacy rule overhead. - Transition from broad wildcard keep rules to precise, type-safe, generated annotations. - Prevent optimization regressions with new Android CLI tools. ## Summary - Google Play enforces app-quality thresholds requiring more than 25% code optimization. Meeting them reduces memory usage while improving start-up speed and ANR rates. - The R8 Configuration Analyzer generates an HTML report showing which keep rules retain code. It highlights subsumed and unused rules and measures optimization potential before compilation. - Overly broad keep rules, often introduced to prevent reflection crashes or inherited from libraries, undermine app optimization. A single package-wide wildcard rule can keep dozens of unused classes. - Jetpack Keep uses lint to detect reflection and generate precise annotations and conditional keep rules directly from code. It exports standard consumer rules compatible with older R8 versions. - Android CLI inspects app bundles and AARs using Google Play's exact logic without an upload. It flags problematic rules and exports JSON reports for automated regression testing. ## Resources - \[App quality memory optimization blog
