# Powering interactive surfaces with Remote Compose - Speakers: Nicolas Roard (Sr Staff Software Engineer), John Hoford (Developer), John Zoeller (Developer Relations Engineer) - Track: Apps foundation - Video: https://www.youtube.com/watch?v=csh2Opo_wjE - Page: https://developer.android.com/events/dev-summit/talks/powering-interactive-surfaces-with-remote-compose ## About the talk Remote Compose introduces a new way to project expressive and interactive UI onto remote surfaces like widgets. By serializing layouts into compact binary payloads, RemoteCompose decouples UI from host execution to deliver significant advantages. Key benefits include edge interactivity that enables high-performance rendering through local execution on the remote device, fluid scaling that allows UIs to reflow across diverse form factors via remote-side component evaluations, and a unified developer workflow that removes the need for platform-specific remote UI frameworks through familiar Jetpack Compose APIs. This session unpacks these benefits and provides live production examples, including modern Wear OS Widgets and the glanceable Wear Workout Tracker experience in Runkeeper. ## Summary - Remote Compose packages UI into a compact binary document instead of sending an app or screen copy across process boundaries. - Developers create documents using Compose APIs or JSON. Android Studio provides live previews while writing composables. - Loaded documents run by themselves directly on the player. They handle events such as resizing and touch without round trips to its creator. - Built-in optimizations such as component templates and document compression shrink payloads down to a few kilobytes. - Jetpack Glance emits Remote Compose documents for launcher widgets and Wear OS widgets. This decouples the UI from app execution to save battery. ## Resources - \[ASICS Runkeeper Wear OS open beta\](https://goo.gle/runkeeper-wearos) - \[Migrating Wear OS tiles to
