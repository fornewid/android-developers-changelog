# Building a Formula E co-driver on Android with ML Kit and Gemini Nano - Speakers: Alastair Breeze (Staff Software Engineer - Google Cloud's Office of the CTO), Oli Thompson (Junior Data Scientist, Formula E) - Track: Intelligent Apps - Video: https://www.youtube.com/watch?v=nV63eqjPeEI - Page: https://developer.android.com/events/dev-summit/talks/building-a-formula-e-co-driver-on-android-with-ml-kit-and-gemini-nano ## About the talk A racing car is a demanding environment of high speed, heat, and telemetry constraints. How can an on-device agent help process real-time vehicle data for sports and engineering applications? This technical session explores an experimental hybrid architecture combining edge hardware and cloud agents. We'll walk through a research proof-of-concept using a Raspberry Pi to stream CAN bus telemetry, a Pixel phone running an on-device conversational agent powered by ML Kit and Gemini Nano, and an agent-to-agent (A2A) Cloud connection for post-race workflows. ## Summary - Formula E race environments challenge edge AI with extreme heat and low latency requirements. A Pixel phone hosted an agent to answer drivers traveling over 200 km/h. - Android hosts the edge architecture using Agent Developer Kit and Gemini Nano through ML Kit. Edge agents can converse directly with cloud agents over the A2A protocol. - Vehicle integration routes live CAN bus telemetry through a Raspberry Pi to publish downsampled 10 Hz data over MQTT. The Android agent combines this data with driver voice input to evaluate queries and speak back. - Track testing at Goodwood proved the phone handled severe heat without issues. Last-minute debugging resolved Bluetooth connections to the driver helmet before the car drove up the hill. ## Topics gemini-nano, ml-kit, on-device-ai, ai-agents, formula-e ## Transcript ###
