# Actionable strategies for reducing your app's Bitmap memory footprint - Speakers: Fung Lam (Developer Relations Engineer) - Track: Tools \& Performance - Video: https://www.youtube.com/watch?v=KD_55WdEYj0 - Page: https://developer.android.com/events/dev-summit/talks/actionable-strategies-for-reducing-your-apps-bitmap-memory-footprint ## About the talk Managing Bitmap memory is critical for mitigating Out-Of-Memory (OOM) risks in visually rich Android apps. While developers know to reduce image sizes, achieving long-term app stability comes from mastering two other key pillars: Reuse and Recycle. This session delivers a practical playbook for optimizing memory performance using modern tools, open-source libraries like Glide and Coil, and system-level APIs. In this session, you will learn how to diagnose real-world memory regressions using Android Vitals, implement advanced caching (Reuse) patterns with Glide and Coil, and proactively release memory (Recycle) using the onTrimMemory callback. ## Summary - Google Play is introducing memory performance thresholds enforced in February 2027. Exceeding the 90th percentile limit directly impacts your app's health assessment and can reduce visibility on the Play Store. - Bitmaps expand by dimensions and color depth when decoded, making them the largest memory consumers in most apps. Just a few full-resolution images can take hundreds of megabytes. - Downsample images and decode only visible regions to reduce memory consumption. Request matching image dimensions via CDN or use APIs like \`BitmapRegionDecoder\` rather than loading oversized full-resolution images. - Multiple image loaders multiply default memory heap cache usage and duplicate stored Bitmaps. Standardize on one loader or set explicit memory budgets across existing loaders. - Release image memory when your app moves to the background by handling \`onTrimMemory\`. Stop background polling and animations in \`onStop\` to prevent background memory growth. ## Resources - \[Android memory documentation\](https://developer.android.com/memory) ## Topics
