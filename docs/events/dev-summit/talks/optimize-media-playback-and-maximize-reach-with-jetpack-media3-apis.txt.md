# Optimize media playback and maximize reach with Jetpack Media3 APIs - Speakers: Donovan McMurray (Developer Relations Engineer), Toni Heidenreich (Software Engineer), Kristina Simakova (Engineering Manager) - Track: Apps foundation - Video: https://www.youtube.com/watch?v=zFs0FLMGAeM - Page: https://developer.android.com/events/dev-summit/talks/optimize-media-playback-and-maximize-reach-with-jetpack-media3-apis ## About the talk Media consumption accounts for a large portion of user time spent on mobile devices, which requires the playback experience to be flawless, highly efficient and mindful of battery life. Furthermore, users expect these experiences to seamlessly transition across their devices, from phones to living room TVs and beyond. Explore how architectural updates in Media3 and ExoPlayer power seamless playback across form factors. The discussion centers on crafting responsive interfaces with the Media3 Compose UI toolkit, eliminating buffering in feeds using the new PreloadManager and extending your app to living room screens and Android XR with CastPlayer and spatial audio. ## Summary - Media3 UI Compose provides ready-made player composables and customizable building blocks. You can override specific control slots while letting the library manage player state and transitions. - A newly rewritten CastPlayer replaces the standalone Cast SDK. It implements the standard player interface and automatically delegates playback between local ExoPlayer instances and remote Cast devices. - The rebuilt editing pipeline decouples from OpenGL and manages hardware buffers directly. This zero-copy approach lowers memory overhead, and decoupling lets developers integrate modern graphic frameworks like WebGPU. - Media3 adds out-of-the-box support for Eclipsa Video and Eclipsa Audio on Android 17 and later. Prescriptive HDR metadata adapts highlights to ambient light, while spatial audio handles multiple mixed presentations. - Built-in optimizations like PCM audio offload reduce screen-off power consumption by up to 20%. The upcoming CodecDB uses benchmark metrics to select device-optimal encoder settings. ## Resources - \[Media3 GitHub repository\](https://github.com/androidx/media) - \[Media3 developer
