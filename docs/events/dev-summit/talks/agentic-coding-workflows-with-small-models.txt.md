# Agentic coding workflows with small models - Speakers: Ian Ballantyne (Technical Member of Staff, Google DeepMind), Jose Alcérreca (Developer Relations Engineer), Zoe Lopez-Latorre (Developer Relations Engineer) - Track: Intelligent Apps - Video: https://www.youtube.com/watch?v=sBWgIjWU6PI - Page: https://developer.android.com/events/dev-summit/talks/agentic-coding-workflows-with-small-models ## About the talk While large frontier models dominate the headlines, small language models (SLMs) like Gemma 4 offer low-latency, cost-effective, and fully offline intelligence to augment daily developer workflows. This talk explores practical patterns for integrating small models into Android development, from smart task routing to cost optimization, using Gemma 4 as our primary hands-on case study to demonstrate real-world use cases and how to configure developer tools and agentic workflows. ## Summary - Small language models offer zero marginal cost and offline access on local hardware. Frontier models cost 20 to 200 times more for the same workloads. - Quantization-aware training cuts memory footprints by 75% with less loss than post-training compression. Speculative decoding then speeds up predictable coding tasks up to 3x. - Evaluating small models requires testing the full stack rather than relying on Python leaderboards. Android Bench provides 100 PR-sized tasks reflecting actual Android development. - Android Bench tests show Gemma 4 solves over half of tasks with its full context window enabled. Long-horizon tasks remain out of reach. - Multi-model orchestration combines frontier and small models through techniques like task cascading and automatic routing. This preserves reliability while reducing token costs. ## Resources - \[Are we there yet? (AWTY) framework\](https://goo.gle/awty) - \[Android Bench\](https://developer.android.com/bench) ## Topics small-language-models, agentic-workflows, benchmarking, gemma, android-studio, evaluations
