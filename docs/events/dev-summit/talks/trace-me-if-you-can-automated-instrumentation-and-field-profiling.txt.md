# Trace me if you can: Automated instrumentation and field profiling - Speakers: Rahul Ravikumar (Staff Software Engineer) - Track: Tools \& Performance - Video: https://www.youtube.com/watch?v=eZtQgeIrmAo - Page: https://developer.android.com/events/dev-summit/talks/trace-me-if-you-can-automated-instrumentation-and-field-profiling ## About the talk Optimizing Android apps requires deep visibility into concurrent workflows and coroutine suspensions. While local profiling offers a useful snapshot, scaling these insights to production without overhead remains a challenge. This session delivers an architectural blueprint for a continuous performance feedback loop. androidx.tracing 2.0: Swap backends dynamically and propagate coroutine contexts (Perfetto flows) across threads. Smart Instrumentation: Use local ART tracing to find hotspots, then automate the injection of low-overhead trace points. Macrobenchmarking: Track regressions and verify performance gains on physical devices in CI. Field Tracing: Go beyond local and CI tracing, with ProfilingManager. ## Summary - Tracing 2.0 replaces older Android tracing APIs to remove label length limits and run seven times faster. It also lets you build custom sinks for backends such as OpenTelemetry. - Context propagation maps causal relationships across threads, coroutines, and processes. You can track asynchronous execution with \`traceCoroutine\` or pass propagation tokens into callback-based code. - Jetpack Compose 1.13 adds Recomposition Tracing, using custom metadata to show why recompositions occur. Traces record the modified state values and the exact call stacks that triggered them. - Android build tools use Tracing 2.0 to spot bottlenecks and speed up builds. Tracing guided optimizations that made R8 code shrinking 25% faster and cut Metalava post-submit times by 15%. ## Topics tracing, android-performance, perfetto, context-propagation, jetpack-compose,
