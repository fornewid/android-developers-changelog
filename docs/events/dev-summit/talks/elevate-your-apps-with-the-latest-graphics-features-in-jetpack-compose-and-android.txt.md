# Elevate your apps with the latest graphics features in Jetpack Compose and Android - Speakers: Rebecca Franks (Developer Relations Engineer), Aayush Chaudhary (Software Engineer), Rahul Ray (Developer Relations Engineer) - Track: Apps foundation - Video: https://www.youtube.com/watch?v=TirZPDPV8Dw - Page: https://developer.android.com/events/dev-summit/talks/elevate-your-apps-with-the-latest-graphics-features-in-jetpack-compose-and-android ## About the talk Ready to take your Android UI from "it works" to "it's a work of art"? Join us for a tour of the latest graphics capabilities in Jetpack Compose. We'll show you how to build new visual effects, from delightful mesh gradients to progressive blurs, and using the powerful new graphics features in Android. We will also show you how to improve the performance of your graphics features, without sacrificing battery life or frame rates. ## Summary - Compose 1.12 introduces mesh gradients for rich multicolor blends across a 2D grid of vertices. On Android 14 and above, you can use the native drawMesh API to build custom geometry-driven visual effects. - Compose supports wide color gamuts to provide smoother gradient blending on supported hardware. Enable wide color gamut mode on your activity or window only when displaying rich media. - Compose 1.13 introduces native \`PolygonShape\` and \`MorphPolygonShape\` APIs for custom geometries. \`MorphPolygonShape\` reads progress during the outline resolution phase, updating shapes frame by frame without triggering recomposition. - Compose 1.13 adds progressive blur, while API level 37.2 introduces \`RenderNode.setBackdropRenderEffect\` for sampling background content. Developers can chain backdrop effects together to create frosted-glass or magnifying effects. - Optimize graphics performance by avoiding unnecessary work across frames. Decode only needed image pixels off the main thread and wrap animating effects in a \`graphicsLayer\`. ## Resources - \[Mesh Gradients Documentation\](https://goo.gle/android-mesh) - \[Understanding Color Guide\](https://goo.gle/understanding-color) - \[Install Android CLI\](https://goo.gle/android-cli) - \[JetChat Sample App\](https://goo.gle/compose-jetchat) ## Topics jetpack-compose,
