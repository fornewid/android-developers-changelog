# Moving beyond 2D with custom 3D geometry in the Jetpack XR SDK - Speakers: Egor Yusov (Software Engineer), Jay Abi-Saad (Software Engineer) - Track: Android XR - Video: https://www.youtube.com/watch?v=mssk4zPs0zU - Page: https://developer.android.com/events/dev-summit/talks/moving-beyond-2d-with-custom-3d-geometry-in-the-jetpack-xr-sdk ## About the talk Transitioning your Android applications from traditional 2D screens into spatial environments requires a new approach to constructing shapes. In this session, we will explore the Custom Mesh API in the Jetpack XR SDK, which allows you to programmatically generate procedural 3D geometry directly at runtime. We will walk through the core workflow, from defining vertex layouts to rendering dynamic objects seamlessly within the user's physical space. By the end of this talk, you will have the practical skills to build interactive, custom 3D geometry completely from code. ## Summary - The glTF introspection API in Jetpack SceneCore exposes model metadata at run time. You can play embedded animations, transform subnodes, or override meshes with materials and textures. - Jetpack SceneCore includes mesh APIs to generate custom 3D geometry in Kotlin. Four building blocks such as VertexLayout and \`MeshBuffer\` construct models triangle by triangle without 3D tools. - Dynamic meshes support real-time updates as users draw paths or animate surfaces. Updating only the changed vertex data streams modifications straight to the GPU without recreating the mesh or entity. - Gemini in Android Studio can write complex vertex animation and lighting math for the mesh APIs. One prompt generates working code that animates vertex grids and recalculates normals every frame. ## Resources - \[Android XR Emulator\](https://goo.gle/xr-tools) - \[Jetpack XR
