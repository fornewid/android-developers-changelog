# Declarative, agent-ready Android builds with Lightbuild - Speakers: Scott Myers (Developer Relations Engineer), Juan Sebastian Oviedo (Senior Product Manager) - Track: Tools \& Performance - Video: https://www.youtube.com/watch?v=0mYQtt2RfoQ - Page: https://developer.android.com/events/dev-summit/talks/declarative-agent-ready-android-builds-with-lightbuild ## About the talk As Android apps grow and AI coding assistants become essential, using executable code to configure your build can create bottlenecks with slow sync times, fragile logic, and added complexity. Enter Lightbuild: Google's declarative, config-driven interface to the build engine, designed for modern Android development. In this session, we'll explore Lightbuild's new approach to managing builds and how to use it to build a demo app. Learn how decoupling build config from execution delivers faster project opens with lightning-fast sync in Android Studio, while offering a predictable schema for safer, more reliable AI editing. We'll also cover Lightbuild's agent-friendly CLI tools for creating reproducible builds across local machines, teams, and CI/CD pipelines ## Summary - Lightbuild is an experimental build system preview for Android apps that replaces executable scripts with purely declarative data files. It uses Gradle as its execution engine under the hood. - Declarative YAML configuration models project structure as a deterministic, static graph. This allows AI agents to inspect topology and safely modify modules or dependencies using a structured schema. - Fast IDE sync bypasses script evaluation by precomputing dependencies into checked-in \`resolved.deps\` files. These files can also serve as lock files during CI/CD builds. - Every project separates code into library modules while keeping application modules as empty shells. This structure accelerates builds and allows distinct application modules to represent flavors such as demo and prod. - A standalone CLI includes commands such as \`query\` and \`resolve\` that can output JSON for agentic workflows. Lightbuild is currently available in Android Studio Canary for experimental use. ## Resources - \[Lightbuild documentation\](https://goo.gle/lightbuild) ## Topics android-builds, lightbuild,
