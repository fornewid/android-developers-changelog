# Lessons from WhatsApp's Wear OS journey - Speakers: Martin Pelant (Software Engineer, Meta), Subhag Bhatia (Software Engineer, Meta) - Track: Apps foundation - Video: https://www.youtube.com/watch?v=Mi3zullvIYY - Page: https://developer.android.com/events/dev-summit/talks/lessons-from-whatsapps-wear-os-journey ## About the talk Hear directly from WhatsApp engineers on how they upgraded their Wear OS app at scale. This session covers the architectural and UX decisions behind integrating Material 3 and adopting Wear Widgets. Gain direct insight into the lessons, patterns and tools the team used to update their app and deliver a cohesive user experience. ## Summary - Sharing Android phone code with Wear OS cuts duplicate work but requires dependency injection and manifest overrides. Tests should compare multibinding sets so modularized features do not silently disappear. - Runtime notification bridging management prevents duplicate alerts while letting the watch operate independently. Turning bridging off at login and back on at logout stops phone mirrors from double-buzzing. - Material 3 migrations on round displays require managing behavioral changes alongside visual styling. Using \`TransformingLazyColumn\` properly means applying transformations at only one level and avoiding caching positions with Compose's \`remember\`. - App expiry limits can trigger sudden active user drops if watches fail to update promptly. Scheduled update reminders direct users to Google Play before their ninety-day build expires. ## Topics wear-os, material-3, jetpack-compose, modularization, notifications, tiles-and-widgets ##
