# Building type-safe deep links with Jetpack Navigation3 - Speakers: Clara Fok (Software Engineer), Ian Lake (Engineering Manager) - Track: Apps foundation - Video: https://www.youtube.com/watch?v=cgmY14gf4zg - Page: https://developer.android.com/events/dev-summit/talks/building-type-safe-deep-links-with-jetpack-navigation3 ## About the talk Managing deep links across modular Android apps can easily lead to broken routes and runtime surprises.This session unpacks Jetpack Navigation3's new type-safe deep linking architecture for Compose to help you build a robust and scalable routing system. We'll explore how to implement out-of-the-box deep link matching APIs, write custom serializers for complex type-safe arguments, and construct dynamic hierarchical back stacks that keep user navigation predictable. ## Summary - Navigation 3 deep link APIs turn incoming deep link requests into navigation keys to determine your initial back stack. The KMP-compatible \`DeepLinkRequest\` class encapsulates the input, including an Android Intent constructor. - A \`UriDeepLinkMatcher\` uses Kotlin Serialization to match URI patterns and deserialize arguments into type-safe \`NavKey\` properties. Primitive types work automatically, failing matches if values cannot be parsed. - Developers can extend \`DeepLinkSerializer\` or override \`matchArguments\` to handle complex deep link strings. Subclassing \`UriDeepLinkMatcher\` lets you preprocess raw URI placeholders before Kotlin Serialization runs. - Calling \`withBackStack\` on matchers creates synthetic back stacks lazily for the best match. This ensures proper system back behavior without computing unnecessary back stacks for every other valid match. ## Resources - \[Nav3 recipes repository\](https://goo.gle/nav3-recipes) - \[Now in Android sample app\](https://github.com/android/nowinandroid) ## Topics jetpack-navigation-3, deep-links, kotlin-serialization, kotlin-multiplatform, android-architecture ## Transcript ###
