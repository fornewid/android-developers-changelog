# On-device intelligence: Optimized performance and quality using Android ML Kit APIs - Speakers: David Chou (PM, AICore) - Track: Intelligent Apps - Video: https://www.youtube.com/watch?v=p-SZ1rWvErU - Page: https://developer.android.com/events/dev-summit/talks/on-device-intelligence-optimized-performance-and-quality-using-android-ml-kit-apis ## About the talk In this session, we'll explore different GenAI use cases using ML Kit APIs to understand when on-device GenAI is ideal for an app and also understand how to evaluate existing GenAI use cases to see if on-device models can satisfy their quality bar. ## Summary - On-device AI offers major advantages in speed and privacy over cloud inference. Internal testing shows a 2x speedup compared to running models in the cloud. - Gemini Nano memory usage dropped from 3.6 GB to 1.1 GB. Key optimizations include 2-bit quantization and a shared KV cache. - Prefix caching and speculative decoding significantly accelerate inference. Reusing system prompts cuts processed tokens by 60%, while a smaller drafter model delivers an average 2x speedup. - New on-device capabilities expand app interactions through speech translation and function calling. Adding thinking mode raises tool-calling accuracy on Gemini Nano 4 by 13 points out of 100. - Multimodal embeddings combine with AppSearch to store and retrieve data through cosine similarity. Your app executes the search logic locally, protecting user privacy and data security. ## Resources - \[Prompt API Android documentation\](https://developers.google.com/ml-kit/genai/prompt/android) ##
