# Agentic coding: A roundtable with industry leaders (London) - Speakers: Arnaud Giuliani (CPTO \& Co-founder @ Kotzilla), Christos Gkekas (Software Engineer), Iury Souza (Senior Engineer, SumUp), Maia Grotepass (Staff Engineer Android, Qonto), Slobodan Manojlović (VP, Lead Software Engineer), Tristan Hamilton (Technical Lead, HubSpot), Jose Alcérreca (Developer Relations Engineer) - Track: Tools \& Performance - Video: https://www.youtube.com/watch?v=iQ0R0EfOBiw - Page: https://developer.android.com/events/dev-summit/talks/agentic-coding-a-roundtable-with-industry-leaders-london ## About the talk As new tools rapidly reshape modern software engineering, this panel will explore how companies and developers are leveraging agentic coding, automated agents, and specialized developer tooling in their daily workflows. We aim to highlight practical applications, discuss measurable productivity improvements, and candidly address the challenges engineering teams face when integrating these tools at scale. ## Summary - Code generation shifts development bottlenecks across the pipeline. Once teams accelerate code reviews, new constraints emerge around live experiments and safe production releases. - Specialized agent teams can replace single general assistants across complex domains. Teams build distinct agents for areas such as performance or logging, coordinating them through routers or shared pools. - Autonomous pull requests require guardrails and clear human accountability. Some workflows auto-submit routine fixes for tech debt, but each PR points back to a designated owner and relies on strict automated checks. - Harness engineering needs centralized shared tooling alongside room for experimentation. Teams maintain core infrastructure for shared concerns such as logs and crashes while pruning inactive skills through automated scripts. - Local developer hardware is strained by concurrent agent-driven builds. Engineers encounter exhausted memory and slow machines when agents trigger multiple Gradle builds simultaneously. ## Topics agentic-coding, ai-tooling, code-review, harness-engineering,
