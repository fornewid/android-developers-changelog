# Android developer verification: Paths for Play, third party app distributors, and hobbyists - Speakers: Rob Clifford (Developer Relations Engineer, Android Trust \& Safety), Naheed Vora (Senior Product Manager) - Track: Tools \& Performance - Video: https://www.youtube.com/watch?v=UL31gug0oS4 - Page: https://developer.android.com/events/dev-summit/talks/android-developer-verification-paths-for-play-third-party-app-distributors-and-hobbyists ## About the talk Android Developer Verification is crucial for a safer ecosystem. This session breaks down the compliance pathways for all developers, from large studios to hobbyists. We will outline the key requirements for publishing on Google Play and third-party app stores. The talk will feature a live demo of the new Limited Distribution accounts, showing how students and hobbyists can easily and safely share apps. By the end of this session, you will be able to: Understand the 3 main developer verification paths. See the new Limited Distribution account flow live. Identify your specific next steps for compliance. ## Summary - Android developer verification links distributed apps to accountable legal entities to curb financial fraud and burner malware networks. Regional enforcement began across four markets before global enforcement expands next year. - Developers can register through Google Play Console or a dedicated Android Developer Console. Students and hobbyists can register packages for free to share across up to 50 associated devices. - The Android Developer Console API enables third-party stores and developers to programmatically automate app registrations and resolve package conflicts. The Android Developer Status API checks whether package names are registered. - Experienced users can sideload unregistered apps by enabling Advanced Flow in developer options. This path enforces a device reboot and a 24-hour countdown to disrupt social engineering scams. ## Resources - \[Developer Console Documentation\](https://developer.android.com/console) ## Topics
