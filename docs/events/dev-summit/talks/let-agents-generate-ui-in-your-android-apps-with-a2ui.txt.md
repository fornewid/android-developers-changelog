# Let agents generate UI in your Android apps with A2UI - Speakers: Anton Beloglazov (Software Engineer), Nick Butcher (Product Manager) - Track: Intelligent Apps - Video: https://www.youtube.com/watch?v=qIvsFGvlHdo - Page: https://developer.android.com/events/dev-summit/talks/let-agents-generate-ui-in-your-android-apps-with-a2ui ## About the talk A2UI is transitioning from web-centric components to native Android. The new Jetpack Compose renderer for A2UI v0.9 enables developers to render dynamic, LLM-generated UI natively. Instead of webviews, it leverages a Coroutine-driven actor framework, sealed-class lifecycles, and native Material 3 integration. This session walks through the new architecture, explaining how server-driven component trees translate into reactive Compose nodes, and how built-in layout transitions handle structural updates smoothly without blocking the UI. ## Summary - A2UI provides a declarative, open JSON protocol for agentic back ends to describe dynamic user interfaces instead of text responses. - The protocol revolves around catalogs that define allowed components and functions, along with surfaces that represent agent-controlled UI pieces. - Jetpack Compose's A2UI library renders streamed surface models natively using Material 3 components with built-in accessibility and progressive rendering. - In-memory data models update bound UI elements instantly without contacting the agent, while outbound events route user actions back. - Developers can customize existing catalog items or create custom components to strictly control what the agent can display. ## Resources - \[A2UI Compose documentation\](https://goo.gle/a2ui-compose-docs) - \[Material 3 A2UI demo\](https://goo.gle/material3-a2ui-demo) - \[JetPacker sample app\](https://github.com/android/ai-samples) - \[A2UI specification\](https://a2ui.org) ## Topics a2ui, generative-ui, jetpack-compose, android, ai-agents, material-design ## Transcript ### Introduction to generative UI and A2UI
