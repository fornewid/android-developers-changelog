# Unlock agentic capabilities in your app with ML Kit GenAI - Speakers: Jolanda Verhoef (Developer Relations Engineer), Victoria Lestari (Software Engineer) - Track: Intelligent Apps - Video: https://www.youtube.com/watch?v=tAy7IifZXG0 - Page: https://developer.android.com/events/dev-summit/talks/unlock-agentic-capabilities-in-your-app-with-ml-kit-genai ## About the talk Take your Android AI features to the next level by building autonomous on-device agents. In this session, we dive into ML Kit's new agentic APIs, built directly on top of the direct model access APIs you already know. Using the open-source Jetpacker app, you'll learn how to chain multi-step actions across local data, manage stateful multi-turn sessions with isolated contexts, and wire up Android MCP to power both in-app assistants and Android system-level surfaces with a single codebase. ## Summary - Gemini Nano 4 natively supports Function Calling, letting on-device models translate natural language into actions and drive local APIs. - The Jetpack AppFunctions library defines tools through natural-language KDoc descriptions. Changing access levels can expose these functions to system agents such as Gemini. - The new agentic flows library (alpha) in ML Kit GenAI simplifies building agents by handling the execution loop and tool calls. - \`AgentRunner\` coordinates tool execution and provides session methods for multi-turn conversations without losing context. - Direct access via the Prompt API remains available for simple history control or complex setups like multi-agent and hybrid systems. ## Skills - \[Android Skills\](https://goo.gle/android-skills) ## Resources - \[Jetpacker sample code\](https://goo.gle/jetpacker) - \[AICore Developer Preview\](https://goo.gle/aicore-dev-preview) ## Topics ml-kit, on-device-ai, gemini-nano, ai-agents, function-calling, app-functions, aicore ##
