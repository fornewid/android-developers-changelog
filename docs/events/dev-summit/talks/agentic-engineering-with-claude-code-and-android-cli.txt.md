# Agentic engineering with Claude Code and Android CLI - Speakers: Steven Jenkins (Product Manager, Android Studio), Ben Trengrove (Developer Relations Engineer) - Track: Tools \& Performance - Video: https://www.youtube.com/watch?v=Mb9H43ia0kE - Page: https://developer.android.com/events/dev-summit/talks/agentic-engineering-with-claude-code-and-android-cli ## About the talk Stop copy-pasting into AI chat windows and start delegating to your agent. This practical, example-driven session shows you how to level up your agentic engineering using Claude Code and the Android CLI. We will walk through a complete workflow to automate complex development tasks and ship features faster. You will learn to: - Optimize the token efficiency of your harness using Android CLI, Skills, Hooks and MCP. - Offload and parallelize long-running tasks to subagents. - Set up continuous verification loops that stop early termination and run until tests pass. ## Summary - Android CLI gives coding agents shell access to Android tools such as emulators and Firebase Crashlytics. It sits in your shell space and works across agents. - Keep agent conversations to around 150,000 tokens to prevent context rot. Slice work into scoped issues and run Gradle in quiet mode to avoid long logs. - Keep \`AGENTS.md\` under 250 lines and reserve it for permanent rules such as architecture constraints. Letting an agent edit this file degrades performance and raises costs. - Deterministic hooks and context-specific skills manage agent actions better than sprawling files. Install only vetted skills or start with the base Android CLI skill. - Verification loops stop developers from acting as manual QA testers. Tier checks to run fast unit tests first and slow emulator runs last. ## Resources - \[Android CLI installation\](https://goo.gle/android-cli) - \[Agent modification study\](https://arxiv.org/pdf/2602.11988) - \[Android Bench\](https://developer.android.com/bench) ## Topics claude-code, android-cli, agentic-engineering, benchmarking, performance ## Transcript ###
