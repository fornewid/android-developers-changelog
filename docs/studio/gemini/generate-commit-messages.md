When committing changes to your version control system from the IDE, the agent
can use the context from the code changes in the current commit and recent past
commits to suggest a detailed commit message. To generate a commit message,
click **Suggest commit message**
![](https://developer.android.com/static/studio/gemini/images/suggest-commit-message-icon.png)
above the text input field in the **Commit** tool window.
![Commit dialog showing a suggested message for the commit.](https://developer.android.com/static/studio/gemini/images/commit-message-generation.gif) The agent can suggest a detailed message for your commit.
