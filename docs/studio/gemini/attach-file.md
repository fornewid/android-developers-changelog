You can attach your project files as context in chat interactions with the
agent. This lets you quickly reference files in your prompts for the agent,
which helps the agent identify the files that your query is about.

To attach a file to your query, in the chat input, type `@` to bring up a
file completion menu. Search for the filename you want and select the file to
attach it. You can attach multiple files in a single query.
![@File context in the agent](https://developer.android.com/static/studio/gemini/images/file-context.png) @File context in the agent

To un-attach a file, click the "x" that appears next to the attached file.
