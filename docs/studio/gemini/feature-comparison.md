Gemini in Android Studio is available in different editions for different use
cases. [Choose the product tier](https://developer.android.com/studio/gemini/overview#choose-tier) and edition that are right for you.

## Individual

The individual tier is most suitable for student, hobbyist, open source, and
freelance developers. The tier includes a free option and membership in Google
One. The following table lists some key features available in the individual
tier.

> [!NOTE]
> Google One AI Pro and AI Ultra memberships include additional benefits such as higher rate limits, Gemini in Google Docs and Gmail, higher usage limits on products such as Nano Banana and NotebookLM, and 2 TB or more of cloud storage. [Find the right Google One plan for you](https://one.google.com/intl/en_us/about/google-ai-plans/#compare-plans).
>
> If you already subscribe to Google One, you automatically get the Gemini in Android Studio added benefits at no cost.

| Gemini in Android Studio | Free | API key | Google One AI Pro | Google One AI Ultra |
| Rate limits | Limited | Higher | Higher | Highest |
| Context window | Limited | Pay per token | Expanded | Expanded |
| Data used for AI training (See [Data and privacy](https://developer.android.com/studio/gemini/data-and-privacy)) | Yes | No | No | No |
| Core AI features including - Agent Mode - Next Edit Prediction - Automate dependency updates - Add an MCP server - Skills | Included | Included | Included | Included |
| Add an API key | Included | Included | Included | Included |
| Configure context sharing with `.aiexclude` files | Included | Included | Included | Included |
| Android UI development - Generate Compose previews - Transform UI - Generate UI with image attachments | Included | Included | Included | Included |
| Android integrations - Fix build errors - Get help with Logcat crashes - Analyze crashes in App Quality Insights | Included | Included | Included | Included |
| Test with Journeys with Gemini | Included | Included | Included | Included |
|---|---|---|---|---|

## Business

The business tier is for IT administrators and professional developers who work
in a business. You can get access to the business tier by subscribing to [Gemini
Enterprise](https://cloud.google.com/gemini-enterprise) or joining the [Google Developer Program](https://developers.google.com/program). The business tier
includes all the features in the individual tier, in addition to
enterprise-grade features including those listed in the following table.

| Business tier | Gemini Enterprise Standard/Plus editions |
| Enterprise governance Operate under your project's existing Google Cloud Terms of Service with centralized administrative controls. | Included |
| Data residency and security - [Private UI access](https://docs.cloud.google.com/gemini/enterprise/docs/private-ui-access) - [VPC Service Controls](https://docs.cloud.google.com/gemini/enterprise/docs/use-vpc-service-controls) | Included |
| Consolidated billing Pay-as-you-go directly with your existing Google Cloud Billing account with unified invoicing. | Included |
|---|---|
