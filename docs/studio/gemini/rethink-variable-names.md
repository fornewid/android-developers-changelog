The agent streamlines your workflow and makes it easier to keep
your code organized with AI-powered refactoring features. You can ask the agent
for variable name suggestions and quickly update all instances of the variable
name in the current file.

If you want to rename a specific variable, class, or method, highlight the
variable, right-click, and select **Rename** to get suggestions (it might take a
second for the agent's suggestions to appear). The agent suggests appropriate
names based on the code context. Double-click on a suggested name to update all
instances of the variable name.
