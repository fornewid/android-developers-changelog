# Start with an idea. Build with AI. Ship on Android


Whether you're exploring AI-assisted development, building with your favorite code editors
and terminal agents, or developing apps professionally in Android Studio, Google's Android
workflows help you turn prompts into real Android experiences.
[Learn more](http://developer.android.com/ai-tools/guides)

Refine, test, and prepare your app for release with AI in Android Studio. Generate live Compose previews, run integrated emulator tests, and diagnose issues with App Quality Insights.

## Featured agentic workflows

[![](http://developer.android.com/static/images/ai-tools/workflow-journeys.png)](http://developer.android.com/tools/agents/android-cli/journeys)

### [Test user journeys with AI](http://developer.android.com/tools/agents/android-cli/journeys)

Automate end-to-end testing across entire app experiences. Use Journeys in Android Studio or Android CLI to simulate user interactions, validate UI behaviour, and identify issues before release. [Learn more](http://developer.android.com/tools/agents/android-cli/journeys) [![](http://developer.android.com/static/images/ai-tools/workflow-port-apps.png)](http://developer.android.com/tools/agents/workflows/app-migrations)

### [Port your apps to Android](http://developer.android.com/tools/agents/workflows/app-migrations)

Accelerate cross-platform conversions with migration guides. Use the Android Studio migration toolset to translate iOS, Web, and Flutter codebases into modern Kotlin and Jetpack Compose for Android devices. [Learn more](http://developer.android.com/tools/agents/workflows/app-migrations) [![](http://developer.android.com/static/images/ai-tools/workflow-compose-ui.png)](http://developer.android.com/studio/gemini/generate-compose-previews)

### [Accelerate UI development with Compose design tools](http://developer.android.com/studio/gemini/generate-compose-previews)

Transform design mockups into idiomatic Jetpack Compose code with AI assistance. Describe UI changes in natural language, generate instant Compose Previews, and iterate on layouts directly in your project. [Learn more](http://developer.android.com/studio/gemini/generate-compose-previews)

## Knowledge grounding and evaluation

Feature

### [Equip agents with Android skills](http://developer.android.com/tools/agents/android-skills)

Configure your coding agents with modular capability packages containing verified domain knowledge. Provide authoritative grounding for Android features and development frameworks like Jetpack Compose, modern Android architecture, identity APIs, and platform APIs to help eliminate hallucinations and outdated code patterns. ![](https://developer.android.com/static/images/ai-tools/grounding-android-skills.png) [Learn more](http://developer.android.com/tools/agents/android-skills) Feature

### [Give your AI trusted Android knowledge](http://developer.android.com/studio/gemini/access-helpful-resources#android-knowledge-base)

Help AI agents generate more reliable Android code by connecting them to authoritative Android documentation, APIs, sample code, and platform guidance. Reduce guesswork and keep development grounded in up-to-date Android best practices. ![](https://developer.android.com/static/images/ai-tools/grounding-trusted-knowledge.png) [Learn more](http://developer.android.com/studio/gemini/access-helpful-resources#android-knowledge-base) Feature

### [Measure AI performance on Android](http://developer.android.com/bench)

Explore Android Bench to see how models perform on real Android development tasks. Compare task completion rates, efficiency, and accuracy across different model capabilities. ![](https://developer.android.com/static/images/ai-tools/grounding-android-bench.png) [Learn more](http://developer.android.com/bench) Feature

### [Orchestrate parallel agents with Git worktrees](http://developer.android.com/tools/agents/workflows/parallel-agents)

Run multiple AI agents concurrently on a single Android codebase without file collisions or build conflicts. Configure isolated Git worktrees, set up shared Gradle build caches, and coordinate parallel agents across complementary tasks, such as generating Compose layouts while independently executing unit tests. ![](https://developer.android.com/static/images/ai-tools/grounding-git-worktrees.png) [Learn more](http://developer.android.com/tools/agents/workflows/parallel-agents)
