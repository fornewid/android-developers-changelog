> Documentation index: https://developer.android.com/games/playgames/native-pc/setup/llms.txt

If you are developing games using the Unity Game Engine, you will benefit a lot
from using the `PlayPcSdkManaged.unitypackage` to install the SDK immediately to
your Unity project rather than developing the C# to C++ glue code yourself.

Download the [tgz](https://developer.android.com/games/playgames/native-pc/downloads/unity) artifact and follow the instructions
in [Add PC SDK to a game](https://developer.android.com/games/playgames/native-pc/setup.md.txt), paying close attention to the
differences between C++ and C# code snippets
