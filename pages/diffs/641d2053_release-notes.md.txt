+## Version 1.1.16919734 (November 2026)
+
+- **Delta installs reuse repositioned files** : `android install` and `android run` no longer resend unchanged files whose position in the APK changed. To disable, pass `--use-delta-install-instructions=COPY,DATA`.
+- **Compose tracing** : `android profiler systemtrace` can record what Jetpack Compose does in an app. Pass `--enable=compose.composition` to record a slice for each composable function that runs, or `--enable=compose.recomposition` to also record the state reads and writes that cause recompositions. The app needs `androidx.compose.runtime:runtime-tracing` 1.13 or newer. The trace is saved as a ZIP archive that you open in the Android Studio profiler.
+- **Perfetto heap dumps** : Pass `--type=perfetto` to `android profiler heapdump capture` to record the heap dump as a Perfetto trace. It has the objects and the references between them, but not their values, so it's smaller than an `.hprof` file. It requires Android 12 (API level 31) or higher, and an app that is profileable or debuggable.
+- **Library DEX size format in analyze JSON** : In `android analyze --format=json` output for library artifacts (AARs and JARs), the `dexSizeBytes` fields in `d8CompileResult` and `r8CompileResult` are now 64-bit integers serialized as strings instead of numbers.
+- **Input results as JSON** : `android input` subcommands print their result as a JSON object with a `results` list on standard output, in the same format for every subcommand. Failures such as no matching elements or multiple matches are reported in each result's `status` field instead of as text on standard error.
+- **Emulator exit codes** : `android emulator create`, `start`, `stop`, and `remove` now exit with a non-zero code on failure and print errors to standard error.
