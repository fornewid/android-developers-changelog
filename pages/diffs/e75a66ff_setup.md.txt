 ## Activate Compose compiler
 
 Set the following options to ensure that the Compose compiler is available for
 Glance:
 
+```
+android {
+   buildFeatures {
+      compose true
+   }
+
+   composeOptions {
+      kotlinCompilerExtensionVersion = "1.5.15"
+   }
+
+   kotlinOptions {
+      jvmTarget = "1.8"
+   }
+}
+```
