-- **Package the WAB:** Use the Play Publishing Tool to package your game into a Windows App Bundle (WAB). The WAB file must be under the 10 GB file size limit. For more information, see the [Packaging guide](https://developer.android.com/games/playgames/native-pc/publish/developer-installed).
+- **Package the WAB:** Use the Play Publishing Tool to package your game into a Windows App Bundle (WAB). The WAB file must be under the 10 GB file size limit for Installer Publishing and 200 GB for Play Managed Publishing. For more information, see the [Packaging guide](https://developer.android.com/games/playgames/native-pc/publish/developer-installed).
+- **Use the latest SDKs and tools:** Compile and package your release with the [latest versions](https://developer.android.com/games/playgames/native-pc/downloads) of the Play Games PC SDK, Play Games PC Unity SDK, Play PC developer tool, and Play publishing tool.
 - **Confirm if elevation is required:** If your Installer, Launcher, or Uninstaller needs to be run as admin every time it is launched, remember to check whether you have set `INSTALLER_REQUIRES_ELEVATION`, `LAUNCHER_REQUIRES_ELEVATION`, or `UNINSTALLER_REQUIRES_ELEVATION` to `true`. Otherwise, they won't run with admin privileges, which will lead to startup failure. See [WAB Config File Format](https://developer.android.com/games/playgames/native-pc/publish/developer-installed#convert-wab) for more details.
 - **Submit third-party launcher installers:** If you use a third-party launcher, submit its installer inside the WAB. For more information, see the [Installer publishing guide](https://developer.android.com/games/playgames/native-pc/publish/developer-installed).
 - **Handle Auto-Play session token:** If you enable Auto-Play by setting `acceptsCommandLineArguments="true"` in `play_publishing_config.xml`, verify that your installer extracts the `--g_session_token=<token>` command-line argument and uses it to launch the game. Make sure your installer handles the fallback case where the token isn't present. For more information, see the [Launcher FAQ](https://developer.android.com/games/playgames/native-pc/faq#Launcher).
