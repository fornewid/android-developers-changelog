 ## Automated Backup Restore Test Version 1.0
 
+### Version 1.0.0-alpha04
+
+November 04, 2026
+
+`androidx.test.backup:backup:1.0.0-alpha04` and `androidx.test.backup:backup-host:1.0.0-alpha04` are released. Version 1.0.0-alpha04 contains [these commits](https://android.googlesource.com/platform/frameworks/support/+log/3566803898b060d7136357220affc9ece8236019..a021adf44194ae86e596ae25ca43d5e4e18f6926/test/backup).
+
+**New Features**
+
+- Added `StorageDomain.DataStorePreference` to seed and verify Preferences `DataStore` entries, `StorageDomain.CustomData` to run custom device actions, and `StorageDomain.ExcludedData` to verify that excluded data is not restored. ([If127d](https://android-review.googlesource.com/#/q/If127d4dbf62c38ef67fc5e222b6a003a1fb8dde8), [I6190e](https://android-review.googlesource.com/#/q/I6190e2e2f9a72b43d8bff509fd8e3731636d7805))
+- Added `isDeviceProtectedStorage` across `StorageDomain` types to test Device Protected (DE) storage, and added support for `String` `Set` values in `StorageDomain.Preference`. ([Ie96be](https://android-review.googlesource.com/#/q/Ie96beb1bdf8a39d339316b10a7b9ec8f1bac8142))
+- Added a `restoreOn` parameter to `runBackupRestoreFlow` for cross-device restore flows, `BackupRestoreController.uninstallApp()`, and `minApi` and `maxApi` bounds on `@Device`. ([Ifa0e3](https://android-review.googlesource.com/#/q/Ifa0e33017a012e3742ab40f6a5f443f91abb2355))
+- Added `testApplicationId` and a default `applicationId` to `@BackupRestoreConfig`, and registered `BackupRestoreTestRunner` with `InstrumentationRegistry` for device actions. ([Ie96be](https://android-review.googlesource.com/#/q/Ie96beb1bdf8a39d339316b10a7b9ec8f1bac8142), [Ifa0e3](https://android-review.googlesource.com/#/q/Ifa0e33017a012e3742ab40f6a5f443f91abb2355))
+- Updated `BackupRestoreExtension` to automatically save device logs when a test fails and report the saved file paths in the failure message (disable via `androidx.test.backup.device.logs.enabled=false`). ([I7f605](https://android-review.googlesource.com/#/q/I7f6053dd3a1a8e529b248b046920b385cf82c59f))
+
+**API Changes**
+
+- Added `BackupActionResult.data` and `BackupActionResult.getOrThrow()` to read output payloads from device actions, along with `STORAGE_TYPE_DATASTORE_PREFS`, `VALUE_TYPE_DOUBLE`, and `VALUE_TYPE_BYTES` on `BackupActionValues`. ([I6190e](https://android-review.googlesource.com/#/q/I6190e2e2f9a72b43d8bff509fd8e3731636d7805), [If127d](https://android-review.googlesource.com/#/q/If127d4dbf62c38ef67fc5e222b6a003a1fb8dde8))
+- Removed `BackupDeviceAction.phase`, `PHASE_POPULATE`, and `PHASE_VERIFY` (remove the `phase` override from custom actions), as well as the `BackupRestoreExtension(AdbSession)` constructor. ([Ie96be](https://android-review.googlesource.com/#/q/Ie96beb1bdf8a39d339316b10a7b9ec8f1bac8142), [I1a349](https://android-review.googlesource.com/#/q/I1a34914a131160f2aaa109cee01277cd7dbddd52))
+
