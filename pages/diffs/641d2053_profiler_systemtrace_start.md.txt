+### Jetpack Compose (`compose.composition` and `compose.recomposition`)
+
+The `compose` options record what Jetpack Compose does in the app. They require
+`androidx.compose.runtime:runtime-tracing` 1.13 or newer in the app:
+
+- `compose.composition`: Records a slice for each composable function that runs.
+- `compose.recomposition`: Also records the state reads and writes that cause composable functions to recompose, which shows why they recompose. It includes `compose.composition`, and has a high overhead, so use it to debug recompositions, not to measure performance.
+
+The app records these traces itself, so the trace is saved as a ZIP archive that
+contains the system trace and the Compose traces. Open it in the Android Studio
+profiler, which shows them as a single trace.
