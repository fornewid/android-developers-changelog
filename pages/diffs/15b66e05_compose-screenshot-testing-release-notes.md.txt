+### 0.0.1-alpha16
+
+This release introduces support for AGP test suites, HTML test report
+improvements, and bug fixes:
+
+- **Test suites integration** : Added support for running Compose preview screenshot tests with [Android Gradle Plugin (AGP) test suites](https://developer.android.com/reference/tools/gradle-api/9.5/com/android/build/api/dsl/AgpTestSuite). To learn how to configure and run screenshot test suites, see [Screenshot testing with test suites](https://developer.android.com/studio/preview/compose-screenshot-testing-with-testsuites).
+- **HTML test report enhancements**: Added a header metadata card showing test case details (name, method, preview, variant, suite, and status badge) and an error summary box categorizing failures (such as missing reference images or dimension mismatches) with quick copy-to-clipboard functionality.
+- **Dynamic visual diffs**: Visual diffs now use a continuous gradient from subtle highlights for minor pixel shifts to high-contrast emphasis for major differences, preventing nested component changes from being obscured.
+
+This release also includes the following bug fixes:
+

+| [issue #513276596](https://issuetracker.google.com/issues/513276596) | Help ensure that Layoutlib rendering errors fail screenshot tests immediately instead of failing silently or creating blank reference images. |
