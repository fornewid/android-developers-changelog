 ## Card defaults
 
 The following defaults apply to cards:
 
-* **Width**: Cards fill the maximum available width of the display to optimize
-  legibility on display glasses.
-* **Minimum height**: `80.dp`
-* **Text vertical spacing**: `3.dp`
-* **Header shape**: Uses [`RoundedCornerShape`](/reference/kotlin/androidx/compose/foundation/shape/package-summary#RoundedCornerShape(androidx.compose.ui.unit.Dp)) with `24.dp` corners
-* **Content padding**: Defaults to
-  [`GlimmerTheme.componentSpacingValues.medium`](/reference/kotlin/androidx/xr/glimmer/ComponentSpacingValues#medium()). This affects the
-  outermost padding around header images and the content container.
-* **Shape**: Defaults to [`GlimmerTheme.shapes.medium`](/reference/kotlin/androidx/xr/glimmer/Shapes#medium()).
-* **Text rendering**: Uses the default values from
-  [`GlimmerTheme.typography`](/reference/kotlin/androidx/xr/glimmer/GlimmerTheme#typography()) for the following slots:
-
-  + Title: [`bodyMedium`](/reference/kotlin/androidx/xr/glimmer/Typography#bodyMedium())
-  + Subtitle: [`caption`](/reference/kotlin/androidx/xr/glimmer/Typography#caption())
-  + Main content: [`bodySmall`](/reference/kotlin/androidx/xr/glimmer/Typography#bodySmall())
