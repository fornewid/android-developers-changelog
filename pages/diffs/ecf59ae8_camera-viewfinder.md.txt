 ## Version 1.7
 
+### Version 1.7.0
+
+November 18, 2026
+
+`androidx.camera.viewfinder:viewfinder-compose:1.7.0`, `androidx.camera.viewfinder:viewfinder-core:1.7.0`, and `androidx.camera.viewfinder:viewfinder-view:1.7.0` are released. Version 1.7.0 contains [these commits](https://android.googlesource.com/platform/frameworks/support/+log/9046f07948c1e7a89aaec581463730f4d666611b..f10325d8016188131590e7b71ef776064836791f/camera/viewfinder).
+
+**Important changes since 1.6.0:**
+
+**API Changes**
+
+- **Transformation Mode Support** : Added the `TransformationMode` property to `TransformationInfo` to support apps using the `OpenGL` pipeline in `EMBEDDED` mode.
+- **Focus State Tracking** : Added `FocusState` and `FocusMeteringState` constants to the generic viewfinder core. **Note** : These constants were primarily introduced to support the new tap-to-focus and gesture capabilities in the higher-level `CameraXViewfinder` API, but they are exposed in the core modules for developers building custom viewfinder integrations who wish to model camera focus states.
+
+**Bug Fixes**
+- **Transformations Mirroring**: Fixed a critical bug in the mirroring logic within Transformations. This ensures that surface-to-viewfinder matrix calculations correctly mirror the preview when using front-facing cameras or inverted setups.
