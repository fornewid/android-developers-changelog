+## Performance
+
+The following are some best practices for [improving performance](https://developer.android.com/topic/performance/improving-overview):
+
+| Recommendation | Description |
+|---|---|
+| Use R8 to shrink and optimize your app. **Strongly recommended** | [Enable R8](https://developer.android.com/topic/performance/app-optimization/enable-app-optimization) in full mode in your build configuration to remove unused code, obfuscate classes, and rewrite code to improve runtime performance. |
+| Implement Baseline Profiles and Startup Profiles. **Strongly recommended** | Generate [Baseline Profiles](https://developer.android.com/topic/performance/baselineprofiles) and [Startup Profiles](https://developer.android.com/topic/performance/baselineprofiles/dex-layout-optimizations) to pre-compile critical code paths. This significantly reduces [startup latency](https://developer.android.com/topic/performance/issues/launch-time) (TTID and TTFD) and minimizes jank and ANRs. |
+| Test performance with Macrobenchmark. **Strongly recommended** | Use the [Macrobenchmark](https://developer.android.com/topic/performance/benchmarking/macrobenchmark-overview) library to test your app's performance and prevent regressions. |
