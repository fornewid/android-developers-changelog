+### Version 1.14.0-alpha01
+
+November 18, 2026
+
+`androidx.compose.animation:animation-*:1.14.0-alpha01` is released. Version 1.14.0-alpha01 contains [these commits](https://android.googlesource.com/platform/frameworks/support/+log/57354ca42849ed417dfe0f797132477674d917e0..3e55c1ad889c6c0087b0bf6720b1a970b6e8ea3b/compose/animation).
+
+**API Changes**
+
+- Added `ExperimentalAnimationCoreApi` and `ComposeAnimationCoreFlags.isSeekableTransitionStateStartAfterLayoutEnabled` to guard starting `SeekableTransitionState.animateTo` after the target state has composed and completed layout. ([I034e3](https://android-review.googlesource.com/#/q/I034e38d545cf412d49b83cd5394afbc12aa2986b), [b/553804644](https://issuetracker.google.com/issues/553804644))
+- Migrate Compose animation specs (`FloatSpringSpec`, `FloatExponentialDecaySpec`, `KeyframesSpec`, `KeyframesWithSplineSpec`, and `SplineBasedFloatDecayAnimationSpec`) to nanosecond precision, guarded by `ComposeAnimationCoreFlags.isNanosecondAnimationSpecEnabled`. ([Ib9545](https://android-review.googlesource.com/#/q/Ib95455d5a9908b2230eccb60de6d88a088e156aa))
+- Added `SharedTransitionScope.DeferredTransitionBehavior` (`FollowContainer`, `Static`, `SeekToTarget`), `SharedContentConfig.deferredTransitionBehavior`, and `MutableContentTransform.sharedElementProgress` to support seeking shared elements toward their target bounds during the deferred phase of a `DeferredTransition`. Deprecated `permitTransformDuringDeferredTransition`. ([I2fac2](https://android-review.googlesource.com/#/q/I2fac2ac003bdf0d1157b92a4263136a0f4c638ca))
+- Added `InterruptionAwareAnimationSpec` to allow pairing a `FiniteAnimationSpec` with a custom `interruptionSpec` (or itself) when a `Transition`, `animate*AsState`, or `Animatable.animateTo` animation is interrupted mid-flight. ([If85e8](https://android-review.googlesource.com/#/q/If85e82744079499aab7f971359305481e9fe72fd))
+- Allow constructing `MutableContentTransform` from two `MutableTransform` instances via constructor. ([I4054e](https://android-review.googlesource.com/#/q/I4054efbeb63487b07858daddf3fc4f29a7f96c27))
+- Made `SharedTransitionDefaults.EnterTransition`, `ExitTransition`, and `ResizeMode` public. Added `AnimatedContentDefaults` with `ContentTransform`, `SizeTransform`, and `SizeAnimationSpec`. ([Id912e](https://android-review.googlesource.com/#/q/Id912eb6a02e72f723723f722baaaf10bfe58e6ac))
+
+**Bug Fixes**
+
+- Fixed an issue where `SeekableTransitionState.animateTo` skipped initial animation frames when the target content had an expensive first composition or layout pass. ([I383c6](https://android-review.googlesource.com/#/q/I383c636812ef685110e6d6c9dee2c3fa3128cf95), [b/553804644](https://issuetracker.google.com/issues/553804644))
+- `compileSdk` for Compose UI and the Compose libraries that build against it (Animation, Foundation, Material 3, UI Test, UI Tooling, UI `ViewBinding` and Navigation3 UI) updated to 37.2. This will require transitively updating `compileSdk` for all apps and libraries using them. ([I2859d](https://android-review.googlesource.com/#/q/I2859d6c2a90dea97c73f0c19bb1558ee6d076166))
+- When a `MutableContentTransform` or `MutableTransform` is provided during a deferred transition phase, transform properties that are not manually set now default to their resting values instead of the transition's initial values. ([Ia79c4](https://android-review.googlesource.com/#/q/Ia79c40bc4937c5bf613404bc652d49c5323a08bb))
+- Shared elements sought via `MutableContentTransform.sharedElementProgress` now transfer their progress velocity to the bounds animation upon handoff. ([I462c0](https://android-review.googlesource.com/#/q/I462c0b354ae17c2b73c9ea6b7dbda3076e31cdfa))
+- `Modifier.sharedElement` now renders the incoming target element (`pendingTargetState`) during the deferred phase of a `DeferredTransition` while keeping its bounds anchored to the outgoing state until the transition commits. ([If60c7](https://android-review.googlesource.com/#/q/If60c72285e5a99216d8eda27a5591def26cf8c4c))
+- Fixed an issue where shared elements nested under `Modifier.animateEnterExit` lost `MutableContentTransform` placement transformations on handoff from a deferred transition phase. ([Icdcd7](https://android-review.googlesource.com/#/q/Icdcd7f3d1806550441638ed80d30e122c6d7de1f), [b/572520922](https://issuetracker.google.com/issues/572520922))

+### Version 1.13.0
+
+November 18, 2026
+
+`androidx.compose.animation:animation-*:1.13.0` is released. Version 1.13.0 contains [these commits](https://android.googlesource.com/platform/frameworks/support/+log/5e0747401bf56b243e3b5141ae080dc9bc61d29c..ac6d2ce3d991b07d9b981d616bddc6d3ab461eab/compose/animation).

+

This includes `DeferredTransitionState`, `rememberDeferredTransition`, `DeferredAnimatedContent`, `DeferredAnimatedVisibility`, and `TransformScope`. ([Ib6430](https://android-review.googlesource.com/#/q/Ib64300bf3bce149fe8119343be539859c4ae084b), [I7bb7e](https://android-review.googlesource.com/#/q/I7bb7e398e092853a33ce0fc5bc79529b70e3d1d4))

Disposes child composition immediately when hidden, and animates exit transitions by rendering the last captured frame on a `GraphicsLayer`. ([I6c5b3](https://android-review.googlesource.com/#/q/I6c5b336a2dd8303e5e4fa78b927ce4491ec13410))
+- **Graduated Stable APIs** : Promoted `createChildTransition`, `Transition.Crossfade`, `veilOut`, and `unveilIn` to stable APIs. `EnterTransition.with` has been removed; use `togetherWith` instead. ([I38f66](https://android-review.googlesource.com/#/q/I38f6697b35453a94229dca76718c25bfc1792638), [Ied832](https://android-review.googlesource.com/#/q/Ied832a863cfd89eed556e03fda451d8373cd5cda), [I9e3a3](https://android-review.googlesource.com/#/q/I9e3a3441119894f6c82c1be32c43890991b42490))
+- **Transition Configurations** : Made `EnterExitTransitionConfig` public on `EnterTransition` and `ExitTransition`. External libraries can now inspect `EnterTransition` and `ExitTransition` configurations to build custom transition support. ([Idd5a4](https://android-review.googlesource.com/#/q/Idd5a4854816746d1ac74f7b75d6292d145d79002), [b/330152398](https://issuetracker.google.com/issues/330152398))
+- **`DeferredTargetAnimation.value`** : Exposed the current animated value as a public property on `DeferredTargetAnimation`. ([Ie4f6e](https://android-review.googlesource.com/#/q/Ie4f6e751a0a5d118111b1c04d9b0a5ee7217d220), [b/434659224](https://issuetracker.google.com/issues/434659224))
+- **Seekable Transition Crash Fix** : Fixed an issue in `SeekableTransitionState` where zero-duration or interrupted transitions could calculate `NaN` fractions and throw an `IllegalArgumentException`. ([I8f3a9](https://android-review.googlesource.com/#/q/I8f3a9d2e1b4c5a6f7e8d9c0b1a2f3e4d5c6b7a89), [b/555294641](https://issuetracker.google.com/issues/555294641))
