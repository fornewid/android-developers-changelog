+**API Changes**
+
+- Added `CanvasFrontBufferRenderer#execute` API ([Ie82c8](https://android-review.googlesource.com/#/q/Ie82c8fe4b04f23d68a19ffde01fbad0c63d549e6))
+
+**Bug Fixes**
+
+- Fixed a race condition during `GLFrameBufferRenderer` teardown by releasing `SurfaceControl` on the GL thread.
+- Fixed inverted buffer transforms in `CanvasFrontBufferedRenderer` and `LowLatencyCanvasView`.
+- Added fallback display rotation resolution for API \< 32 devices.
+- Fixed visual artifacts on devices that do not preserve buffer contents.
+- Fixed redundant draws and render stalls when surfaces are recreated.
+- Fixed memory leaks by unparenting `SurfaceControl` instances and clearing references on `release()`.
+- Reduced allocations and redundant thread hops during draw loops.
+- Replaced unused `annotation-experimental` dependency with `annotation:1.8.0`.
