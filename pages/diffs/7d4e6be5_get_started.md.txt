 ## Create a tile
 
+### Use `Material3TileService` (recommended)
+
+When building Material 3 tiles (`androidx.wear.tiles:tiles:1.6.0` and higher),
+always extend [`Material3TileService`](https://developer.android.com/reference/kotlin/androidx/wear/tiles/Material3TileService) instead of the lower-level
+[`TileService`](https://developer.android.com/reference/androidx/wear/tiles/TileService) class. `Material3TileService` provides an opinionated,
+Kotlin-first architecture that simplifies tile development:
+
+- **Built-in Kotlin coroutines:** Implement a single suspending `MaterialScope.tileResponse(requestParams: TileRequest): Tile` function instead of using `ListenableFuture` and overriding `onTileRequest()`.
+- **Pre-configured `MaterialScope`:** `tileResponse()` runs with `MaterialScope` as its receiver (configured through constructor parameters such as `allowDynamicTheme` and `defaultColorScheme`), so you don't need to wrap your layout in a redundant `materialScope()` call.
+- **Single-call resource registration:** Includes `ProtoLayoutScope` to automatically register inline image resources and return both the tile layout and resources in a single system binder call. Because `Material3TileService` handles resources automatically (`final` `onTileResourcesRequest()`), don't override `onTileResourcesRequest()`.
+
+```kotlin
+class MyTileService : Material3TileService() {
+
+    override suspend fun MaterialScope.tileResponse(requestParams: TileRequest): Tile =
+        tile(
+            timeline =
+            Timeline.fromLayoutElement(
+                primaryLayout(
+                    mainSlot = {
+                        text("Hello, World!".layoutString, typography = BODY_LARGE)
+                    }
+                )
+            )
+        )
+}
+```
+
