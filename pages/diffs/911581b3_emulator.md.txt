+- Adds online-updateable feature flags for quickly addressing issues stemming from problematic hardware configurations. This allows Google to roll out fixes and features that are dependent on user configurations by updating server-side flags. If you notice issues with specific hardware, please [report a bug](https://developer.android.com/studio/report-bugs.md.txt) so we can investigate the problem.
 - New support for [rotary
   input](https://developer.android.com/training/wearables/ui/rotary-input) for Android Wear API level 25 system images. To emulate the rotary input dial on a Wear device, click the **Rotary Input** tab on the extended window.
 - The Crash Reporting dialog is now resizable and no longer resets **When to send crash reports** to **Ask** without input.
