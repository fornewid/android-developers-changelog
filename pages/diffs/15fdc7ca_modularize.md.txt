+## Modularize deep link matchers
+
+If your app supports [deep links](https://developer.android.com/guide/navigation/navigation-3/deep-links) and is modularized, each feature module
+should define the `DeepLinkMatcher` instances for the destinations it owns.
+
+To collate all matchers from across your app, you can use
+dependency injection multibindings. For example, each feature module can
+contribute its matchers to a Dagger `@IntoSet` multibinding:
+
+**Feature module**
+
+
+```kotlin
+@Module
+@InstallIn(ActivityRetainedComponent::class)
+object FeatureADeepLinkModule {
+    @IntoSet
+    @Provides
+    fun provideUserMatcher(): DeepLinkMatcher<*, *> {
+        return UriDeepLinkMatcher(
+            DeepLinkUri("www.example.com/users/{id}"),
+            serializer<UserProfileKey>()
+        )
+    }
+}
+```
+
+<br />
+
+Then, in your main app module, such as in your `MainActivity`, you can inject
+the set of matchers and use them to match incoming requests:
+
+**App module**
+
+
+```kotlin
+@AndroidEntryPoint
+class MainActivityWithDI : ComponentActivity() {
+    @Inject
+    lateinit var deepLinkMatchers: Set<@JvmSuppressWildcards DeepLinkMatcher<*, *>>
+
+    override fun onCreate(savedInstanceState: Bundle?) {
+        super.onCreate(savedInstanceState)
+
+        val request = DeepLinkRequest(intent = intent)
+        val matchResult = deepLinkMatchers
+            .mapNotNull { it.match(request) }
+            .maxOrNull()
+
+        val backStack = when (matchResult) {
+            null -> listOf(HomeKey)
+            is BackStackMatchResult<*, *> -> {
+                @Suppress("UNCHECKED_CAST")
+                matchResult.backStack as List<NavKey>
+            }
+            else -> listOf(matchResult.key)
+        }
+    }
+}
+```
+
+<br />
+
+For more information about defining and handling deep links, see [Support deep
+links](https://developer.android.com/guide/navigation/navigation-3/deep-links).
+
