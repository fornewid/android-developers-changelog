 ## Version 1.0
 
+### Version 1.0.0-rc02
+
+October 07, 2026
+
+`androidx.xr.scenecore:scenecore-*:1.0.0-rc02` is released. Version 1.0.0-rc02 contains [these commits](https://android.googlesource.com/platform/frameworks/support/+log/6fb59a3b2759476e6992ff0fc2fbb10c833eeeea..2e3660870c84fabc0f4ecdc2f7b87a6f853d7bf1/xr/scenecore).
+
+**Bug Fixes**
+
+- Fixed a potential memory leak by removing the `perceptionRuntimeCache` in `SessionExt` and refactored it to retrieve the `PerceptionRuntime` directly from the `Session` instance. ([Ie35b1](https://android-review.googlesource.com/q/Ie35b122d001f45198b5f9fed88b53fa6345b03c3))
+- Fixed a potential context leak by using `applicationContext` for `OpenXR` native handles to ensure the native runtime does not hold references to an `Activity` context. ([Ie35b1](https://android-review.googlesource.com/q/Ie35b122d001f45198b5f9fed88b53fa6345b03c3))
+- Fixed race conditions in `XrInstanceManager` by introducing proper synchronization and initialization locking. ([Ie35b1](https://android-review.googlesource.com/q/Ie35b122d001f45198b5f9fed88b53fa6345b03c3))
+- Fixed `ReferenceCleaner` to support de-registration of cleaning actions and ensured `Entity` cleanup actions are run explicitly during `dispose()`, preventing duplicate execution upon garbage collection. ([Ie35b1](https://android-review.googlesource.com/q/Ie35b122d001f45198b5f9fed88b53fa6345b03c3))
+- Fixed a memory leak in `Scene` by removing the `sceneCache` in `SessionExt` and refactoring `Scene` to fetch the instance directly from `sessionConnectors`. ([Ie35b1](https://android-review.googlesource.com/q/Ie35b122d001f45198b5f9fed88b53fa6345b03c3))
+
