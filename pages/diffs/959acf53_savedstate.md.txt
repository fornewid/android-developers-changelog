 ## Version 1.6
 
+### Version 1.6.0-alpha02
+
+August 26, 2026
+
+`androidx.savedstate:savedstate-*:1.6.0-alpha02` is released. Version 1.6.0-alpha02 contains [these commits](https://android.googlesource.com/platform/frameworks/support/+log/384f3c27346bf5812f359330dc2310f0cbb66402..f3ed195f0c9ef9eafe437351d974c9ec49ecc2ea/savedstate).
+
+**API Changes**
+
+- Added public constructors to `SavedStateRegistry` and made `SavedStateRegistry` implement `SavedStateProvider` and `SavedStateRestorer`. ([I3c696](https://android-review.googlesource.com/#/q/I3c6965da24b07771b21238110a5cbb207857a0fa))
+- Added top-level `SavedStateProvider` interface. ([I20f9d](https://android-review.googlesource.com/#/q/I20f9ddaa6985ab899269e45057eab27cb13c627e))
+- Added top-level `SavedStateRestorer` interface with `restoreState(savedState: SavedState?)` and removed unreleased `SavedStateRegistry.SavedStateConsumer`. ([Idc01d](https://android-review.googlesource.com/#/q/Idc01d36624ae9ea6e391e28b59282ef9529990ed))
+- `AutoRecreated` and `runOnNextRecreation` are deprecated in favor of `SavedStateProvider` and `SavedStateRestorer`. ([Iadc00](https://android-review.googlesource.com/#/q/Iadc007bb0fcc0699e6ee7e9cfe9df0b81e3ac83b))
+- Introduce `SavedStateConsumer` interface on `SavedStateRegistry`. Allows registered providers to automatically receive and consume restored state during restoration, or immediately upon registration if state is already restored. ([I9a378](https://android-review.googlesource.com/#/q/I9a37878f0ec721c5b1030316e432e322a8bc3a5c))
