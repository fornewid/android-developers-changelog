+## Diagnose heavy memory Critical User Journeys (CUJs)
+
+When investigating memory issues, it is helpful to identify your app's heavy
+memory Critical User Journeys (CUJs). These are specific workflows that
+inherently require significant memory allocation. Common heavy memory CUJs
+include the following:
+
+- Loading and manipulating complex media or large bitmaps.
+- Hosting `WebView` instances.
+
+If your app relies on web content, `WebView` instances can often become a hidden
+memory bottleneck due to their multi-process architecture and native code
+execution. For specific diagnostics, lifecycle best practices, and tools
+tailored to web content, see [Manage and diagnose WebView memory](https://developer.android.com/develop/ui/views/layout/webapps/manage-webview-memory).
+
