+## Compose Material3 A2UI Version 1.0
+
+### Version 1.0.0-alpha01
+
+September 23, 2026
+
+`androidx.compose.material3:material3-a2ui:1.0.0-alpha01` is released. Version 1.0.0-alpha01 contains [these commits](https://android.googlesource.com/platform/frameworks/support/+log/4655a1cce41f181b9bbdb8f0a963f20b1f020101/compose/material3/material3-a2ui).
+
+**New Features**
+
+The Jetpack Compose Agent-to-UI (A2UI) renderer provides an implementation of the [A2UI protocol](https://a2ui.org/), enabling AI agents to generate rich, interactive user interfaces that render native Compose components---without executing arbitrary code. This library provides a ready-to-use implementation of the standard A2UI Basic Catalog specification, built using Material Design 3 components.
