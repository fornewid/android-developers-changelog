+## M3 Expressive update
+
+Material 3 Expressive introduces `ShortNavigationBar` and
+`ShortNavigationBarItem` as additional, flexible options alongside the standard
+`NavigationBar`.
+![Example of a Material 3 flexible navigation bar, with shorter height and icons with labels.](https://developer.android.com/static/develop/ui/compose/images/components/navigation_bar_expressive.png) **Figure 3.** A flexible navigation bar.
+
+For more information about the M3 Expressive updates for navigation bars, see
+the [Material Design 3 navigation bar guidelines](https://m3.material.io/components/navigation-bar/guidelines#895b5b49-a166-4d30-90be-c71a4c970f04).
+
+The navigation items in `ShortNavigationBar` can be arranged **vertically** or
+**horizontally**.
+
+### Navigation bar with vertical items
+
+Use vertical items in compact windows, such as on mobile devices. The following
+snippet demonstrates how to implement a `ShortNavigationBar` with vertical
+items:
+
+
+```kotlin
+@Composable
+fun ShortNavigationBarSample() {
+    var selectedItem by remember { mutableIntStateOf(0) }
+    val items = listOf("Songs", "Artists", "Playlists")
+
+    ShortNavigationBar {
+        items.forEachIndexed { index, item ->
+            ShortNavigationBarItem(
+                icon = {
+                    Icon(
+                        painter = rememberVectorPainter(if (selectedItem == index) AppIcons.FavoriteFilled else AppIcons.Favorite),
+                        contentDescription = null,
+                    )
+                },
+                label = { Text(item) },
+                selected = selectedItem == index,
+                onClick = { selectedItem = index },
+            )
+        }
+    }
+}
+```
+![A short navigation bar with three vertical items showing heart icons above the labels 'Songs' (selected), 'Artists', and 'Playlists'.](https://developer.android.com/static/develop/ui/compose/images/components/previews/android_compose_expressive_components_verticalitemsnavigationbarexample.png) A short navigation bar with vertical items.
+
+<br />
+
+### Navigation bar with horizontal items
+
+Use horizontal items in medium windows, such as on tablets. The following
+snippet demonstrates how to implement a `ShortNavigationBar` with horizontal
+items centered in the bar:
+
+
+```kotlin
+@Composable
+fun ShortNavigationBarWithHorizontalItemsSample() {
+    var selectedItem by remember { mutableIntStateOf(0) }
+    val items = listOf("Songs", "Artists", "Playlists")
+
+    Column {
+        Text(
+            "Note: this configuration is better displayed in medium screen sizes.",
+            Modifier.padding(16.dp),
+        )
+
+        Spacer(Modifier.height(32.dp))
+
+        ShortNavigationBar(arrangement = ShortNavigationBarArrangement.Centered) {
+            items.forEachIndexed { index, item ->
+                ShortNavigationBarItem(
+                    iconPosition = NavigationItemIconPosition.Start,
+                    icon = {
+                        Icon(
+                            painter = rememberVectorPainter(if (selectedItem == index) AppIcons.FavoriteFilled else AppIcons.Favorite),
+                            contentDescription = null,
+                        )
+                    },
+                    label = { Text(item) },
+                    selected = selectedItem == index,
+                    onClick = { selectedItem = index },
+                )
+            }
+        }
+    }
+}
+```
