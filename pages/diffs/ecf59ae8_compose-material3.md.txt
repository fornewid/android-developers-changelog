 ## Compose Material3 Version 1.5
 
+### Version 1.5.0
+
+Nov 18 2026
+
+`androidx.compose.material3:material3-*:1.5.0` is released. Version 1.5.0 contains [these commits](https://android.googlesource.com/platform/frameworks/support/+log/5113b82a4ed6416d6344efa50e41db8cb65928ff..919e948eaa351c590e7e6fc89d4014fad7a6e78c/compose/material3).
+
+**Important changes since 1.4.0:**
+
+**Library change announcements**
+
+- **New `material3-ripple` artifact and Inset Focus Rings** : Added the dedicated `androidx.compose.material3:material3-ripple` artifact as a modern replacement for `material-ripple` ([I1b3a3](https://android-review.googlesource.com/q/I1b3a3e310538661ae4f1bc36bcbd6dd88f044f28)).
+
+This library adds support for rendering focus states using visual inset focus rings instead of opacity layers. Within `material3`, this integrates seamlessly via `LocalRippleThemeConfiguration` ([I0551a](https://android-review.googlesource.com/#/q/I0551ae78abc7faae4afcf3e9ccfbff622b015bd9)). Standalone design systems can also depend directly on `androidx.compose.material3:material3-ripple`.
+
+**Behavior Changes**
+
+- **`Slider` and `RangeSlider` stateful migration \& source-breaking parameter change**:
+
